---
title: App Scopes
description: OAuth scopes required per endpoint for the Go Enterprise API.
---

Go Enterprise API endpoints are protected by OAuth 2.0 scopes. Each endpoint requires one scope. Calling an endpoint without that scope results in `403 Forbidden` errors at runtime.

<Info>
  Scopes are granted at app creation time and cannot be widened afterwards. If your app is missing a scope, you need to create a new app with the correct scope set and obtain consent again.
</Info>

## Available scopes

| Scope | What it covers |
| ----- | -------------- |
| `MediaPlatform_Analytics_Read` | Read access to brand and retailer reporting endpoints |
| `MediaPlatform_Audience_Read` | Read access to audience segments and in-market data |
| `MediaPlatform_Audience_Manage` | Create and manage audience segments and contact lists |
| `MediaPlatform_Campaign_Manage` | Manage ad-set audience targeting |

***

## Endpoint scope requirements

### Analytics

| Method | Endpoint | Required scope |
| ------ | -------- | -------------- |
| `POST` | `/2027-01/media-platform/brand-reporting/report` | `MediaPlatform_Analytics_Read` |
| `POST` | `/2027-01/media-platform/retailer-reporting/report` | `MediaPlatform_Analytics_Read` |
