## Rate Limits

Every call on this page is subject to the **default limit of 250 calls per minute**. Unlike the analytics report endpoints, the partner billing report is not part of the stricter 40 calls per minute reporting allowance.

| Call | Limit |
| ---- | ----- |
| Create a report (`POST /billing/partner-report`) | **250 calls per minute** |
| Report status (`GET /billing/partner-report/{reportId}/status`) | **250 calls per minute** |
| Report output (`GET /billing/partner-report/{reportId}/output`) | **250 calls per minute** |

Calls above the limit return `429 Too Many Requests`, with `x-ratelimit-limit`, `x-ratelimit-remaining`, and `x-ratelimit-reset` headers. See [Rate Limits](/criteo-apis/docs/rate-limits) for the full policy and backoff guidance.
