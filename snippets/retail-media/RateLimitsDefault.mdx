### Rate limits

Calls to this endpoint count against the default rate limit, which depends on the OAuth method your application uses.

| OAuth method | Rate limit |
| --- | --- |
| Client Credentials | 250 calls per minute |
| Authorization Code | 10 calls per minute per account |

See [Rate Limits](/criteo-apis/docs/rate-limits) for the full policy and how to handle `429` responses.
