## Rate Limits

Every call on this page is subject to the **default limit of 250 calls per minute**. Unlike the analytics report endpoints, catalog ingestion reporting is not part of the stricter 40 calls per minute reporting allowance.

| Call | Limit |
| ---- | ----- |
| List ingestions (`GET /catalog/merchants/{merchant-id}/ingestion/reports`) | **250 calls per minute** |
| Ingestion summary (`GET /catalog/ingestion/{ingestion-id}/reports/summary`) | **250 calls per minute** |

Calls above the limit return `429 Too Many Requests`, with `x-ratelimit-limit`, `x-ratelimit-remaining`, and `x-ratelimit-reset` headers. See [Rate Limits](/criteo-apis/docs/rate-limits) for the full policy and backoff guidance.
