Dynamic Seller Logo lets you display each seller's own logo, instead of the marketplace logo, in MPO Single-Seller campaigns. This creates ads that feel more authentic to shoppers, improve brand recognition, and increase trust and click-through.

  ![Single-Seller ad showing a headphones product with the seller's own logo instead of the marketplace logo](/images/marketing-solutions/docs/dynamic-seller-logo.jpg)

<Note>
  Dynamic Seller Logo for Single-Seller Dynamic Ads is planned for late 2026.
</Note>

### Before you start

- You are running **MPO Single-Seller** campaigns.
- You can send product feeds to Criteo and include additional per-product fields.
- You have each seller's logo asset available at a public URL that meets the [logo specifications](#logo-specifications).

### How seller logos work

| Behavior            | Marketplace logo                              | Seller logo                                                              |
| ------------------- | --------------------------------------------- | ------------------------------------------------------------------------ |
| Brand shown | Your marketplace | The individual seller |
| Source | Account-level asset configured with Criteo | `extra_seller_logo_url` field in your product feed |
| Supported campaigns | All MPO campaigns | MPO Single-Seller Coleads |
| Ad format | Coleads and Dynamic Ads | Coleads today; Dynamic Ads planned for late 2026 |
| Logo fallback | N/A | Marketplace logo is used when no seller logo is provided or the URL is invalid |

- **Multi-Seller campaigns are not supported.** Multi-Seller ads continue to show the marketplace logo.
- **Click behavior is unchanged.** Clicks on the seller logo follow the same landing behavior as the rest of the ad.

### Send the seller logo in your product feed

Add the `extra_seller_logo_url` field to each product in the feed you send to Criteo. Populate it with a public URL that points to the seller's logo image.

```xml Product feed
<item>
  <g:id>SKU-12345</g:id>
  <g:title>Wireless Headphones</g:title>
  <g:link>https://marketplace.example.com/products/SKU-12345</g:link>
  <g:image_link>https://cdn.example.com/products/SKU-12345.jpg</g:image_link>
  <extra_seller_logo_url>https://cdn.example.com/sellers/seller-42/logo.png</extra_seller_logo_url>
</item>
```

If `extra_seller_logo_url` is missing, empty, or unreachable, Criteo falls back to the marketplace logo for that impression.

### Logo specifications

| Requirement | Value |
| --- | --- |
| Format | PNG or JPG |
| Aspect ratio | Square (1:1) recommended |
| Minimum size | 200 × 200 pixels |
| Background | Transparent PNG preferred; solid backgrounds are supported |
| Hosting | Publicly accessible HTTPS URL, no authentication required |
| Content | The seller's own brand mark; must comply with Criteo creative policies |

### What to do now

1. Collect each seller's logo asset and host it on a publicly accessible HTTPS URL that meets the [logo specifications](#logo-specifications).
2. Add the `extra_seller_logo_url` field to the corresponding items in your product feed.
3. Send the updated feed to Criteo and verify seller logos appear on your next Single-Seller Colead impressions.
