Dynamic Seller Logo lets Single-Seller campaigns in Marketplace Performance Outcomes (MPO) display the seller's logo instead of the marketplace logo, so the creative reflects the seller being promoted.

This page explains how seller logos work, how to provide them in the product feed, and the logo requirements.

Dynamic Seller Logo for Single-Seller Dynamic Ads is planned for late 2026.

### How seller logos work

| Behavior | Marketplace logo | Seller logo |
| --- | --- | --- |
| Brand shown | Marketplace brand | Seller brand |
| Source | Marketplace configuration | Seller logo URLs supplied through the product feed |
| Supported campaigns | All MPO campaigns | Single-Seller campaigns only |
| Ad format | Dynamic Ads | Dynamic Ads |
| Logo fallback | Not applicable | The marketplace logo is used if no valid seller logo can be rendered |

Clicking the seller logo opens the landing page of the first product shown in the ad. A separate seller or storefront URL is not supported.

### Send seller logos in your product feed

Provide one or more seller logo URLs using the appropriate field:

| Field | Logo orientation |
| --- | --- |
| `extra_seller_logo_url_horizontal` | Horizontal |
| `extra_seller_logo_url_square` | Square |
| `extra_seller_logo_url_vertical` | Vertical |

At least one logo orientation is required.

For best coverage across placements:

- Provide horizontal and square logos where possible. Horizontal is the main format for Dynamic Display banners, while square is especially important for Native placements.
- Add a vertical version when available for vertical or narrow placements.

Criteo automatically uses the available orientation that best fits the placement.

Use the same set of seller logo URLs across products belonging to the same seller.

### Logo requirements

| Specification | Requirement |
| --- | --- |
| File format | JPG or PNG |
| Maximum file size | 5 MB |
| Maximum dimensions | 800 × 2000 px |
| Recommended dimensions | Keep source assets under 600 × 1200 px |
| Background | Transparent preferred; white also supported |

Use a high-resolution logo and leave enough clear space around it. Avoid small text or overly detailed logos that may become difficult to read when scaled down.

### Enable Dynamic Seller Logo

Criteo enables Dynamic Seller Logo on the Single-Seller template. Ad sets created from that template inherit the setting, so no seller-level configuration is required.

Once enabled:

1. Add at least one valid seller logo URL to the product feed.
2. Continue creating and managing campaigns through your existing Single-Seller MPO workflow.
3. Review the delivered creative to confirm the seller logo renders as expected.

If no valid seller logo can be rendered, the marketplace logo is used as the fallback.

For campaign creation and budget management, see [MPO Single-Seller Campaigns](https://developers.criteo.com/marketing-solutions/docs/single-seller-campaigns).
