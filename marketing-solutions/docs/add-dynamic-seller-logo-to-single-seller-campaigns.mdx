Dynamic Seller Logo lets Single-Seller campaigns in Marketplace Performance Outcomes (MPO) automatically display the seller’s logo when one is available in the catalog. If no valid seller logo is available, the logo configured in the creative—typically the Marketplace logo—is shown instead.

This page explains how seller logos work, how to provide them in the product feed, and the logo requirements.

### Before you start

- **Availability:** Dynamic Seller Logo will be available for Single-Seller Dynamic Ads in late 2026.
- **Prerequisite:** You must be using Single-Seller Dynamic Ads.
- **Catalog requirement:** Seller logo data must be provided through the product feed using the supported seller logo fields.
- **Enablement:** Criteo must enable this capability for you.

### How seller logos work

| Behavior | Multi-Seller Logozone | Single-Seller Logozone |
| --- | --- | --- |
| Brand shown | Marketplace brand | Seller brand |
| Source | Marketplace configuration | Seller logo URL(s) supplied through the product feed |
| Supported campaigns | All MPO campaigns | Single-Seller campaigns only |
| Ad format | Dynamic Ads | Dynamic Ads |
| Logo fallback | Not applicable | The logo configured in the creative is used as the fallback |
| Logo click destination | No clickthrough | Seller homepage when `extra_seller_homepage_url` is provided; otherwise, the first product shown |

### Send seller logos in your product feed

Provide one or more seller logo URLs using the appropriate field:

| Field | Logo orientation |
| --- | --- |
| `extra_seller_logo_url_horizontal` | Horizontal |
| `extra_seller_logo_url_square` | Square |
| `extra_seller_logo_url_vertical` | Vertical |

At least one logo orientation is required.

For best coverage across placements:

- Provide **horizontal and square** versions where possible. Horizontal is the main format for Dynamic display banners, while square is especially important for Native placements.
- Add a **vertical** version when available for vertical or narrow placements.

Criteo automatically uses the appropriate available orientation for the placement.

Use the same set of seller logo URLs across products belonging to the same seller.

### Set the seller homepage destination

To direct seller-logo clicks to the seller homepage, provide the URL using:

```text
extra_seller_homepage_url
```

Use the same seller homepage URL across products belonging to the same seller. If this field is not provided, the seller logo links to the landing page of the first product shown in the ad.

### Logo requirements

Once enabled:

1. Add at least one valid seller logo URL to the product feed.
2. Optionally add `extra_seller_homepage_url` to direct logo clicks to the seller homepage.
3. Continue creating and managing campaigns through your existing workflow.
4. Review the delivered creative to confirm the logo and destination behave as expected.
