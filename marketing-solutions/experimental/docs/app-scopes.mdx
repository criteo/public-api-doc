---
title: App Scopes
description: OAuth scopes required per endpoint for the Marketing Solutions API.
---

Marketing Solutions API endpoints are protected by OAuth 2.0 scopes. When creating an app, you must request the scopes that match the operations your integration needs. Requesting too few scopes results in `403 Forbidden` errors at runtime.

<Info>
  Scopes are granted at app creation time and cannot be widened afterwards. If your app is missing a scope, you need to create a new app with the correct scope set and obtain consent again.
</Info>

## Available scopes

| Scope | What it covers |
| ----- | -------------- |
| `MarketingSolutions_Campaign_Read` | Read access to campaigns, ad sets, and campaign configuration |
| `MarketingSolutions_Campaign_Manage` | Create and manage campaigns and ad sets |
| `MarketingSolutions_Analytics_Read` | Read access to analytics and performance reporting endpoints |
| `MarketingSolutions_Audience_Read` | Read access to audiences and audience segments |
| `MarketingSolutions_Audience_Manage` | Create and manage audiences and audience segments |
| `MarketingSolutions_Creative_Read` | Read access to creatives and creative assets |
| `MarketingSolutions_Creative_Manage` | Create and manage creatives and creative assets |
| `MarketingSolutions_Reco_Read` | Read access to product recommendation data |
| `MarketingSolutions_Reco_Manage` | Create and manage product recommendations |
| `MarketingSolutions_Catalog_Read` | Read access to catalog data |
| `MarketingSolutions_Catalog_Manage` | Create and manage catalog data |
| `MarketingSolutions_OnSiteRecommendation_Read` | Read access to on-site recommendation endpoints |

***
