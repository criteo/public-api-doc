title: Get Merchant Brands

---

Retrieve the brands present in a merchant's catalog. This endpoint is new in `2027.01` and not available in stable.

---

## Prerequisites

- **Auth scope**: `retail-media:read` — see [Authentication](/retail-media/v2027.01-rc/docs/authentication)
- **Merchant ID**: the `merchant-id` whose catalog brands to retrieve

---

## Steps

### 1. List merchant brands

[→ `GET /retail-media/catalog/merchants/{merchant-id}/brands`](/retail-media/v2027.01-rc/reference/catalog/get-merchant-brands)

Returns brands available in the merchant's catalog. Use `include-inactive=true` to include brands with no active offers.

```bash
curl -X GET "https://api.criteo.com/2027-01/retail-media/catalog/merchants/987654321/brands?limit=100&offset=0" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Accept: application/json"
```

---

## Verify

A successful response returns HTTP `200` with a `data` array of brand objects. An empty array means the merchant has no brands in their catalog matching the filter.

---

## Constraints

| Limit | Value |
|---|---|
| Default page size | 25; max 100 |
| `include-inactive` | Defaults to `false` — inactive brands excluded unless explicitly requested |
| Availability | New in `2027.01` — not available in stable |
