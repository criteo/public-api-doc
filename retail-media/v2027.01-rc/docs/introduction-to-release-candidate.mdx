The **2027.01 Release Candidate** is a production-ready preview of the next stable Retail Media API. It becomes the official stable release in **January 2027**.

<Info>
  If you integrate `2027-01` now, no migration is needed when stable ships — you're already on the right version.
</Info>

---

## What's new in 2027.01

This RC introduces 5 new endpoints not available in stable:

| Area | What's new |
|---|---|
| Catalog | [Monitor Catalog Ingestion](/retail-media/v2027.01-rc/docs/catalog-ingestion-reporting) — adds a per-field quality report (`GET /catalog/ingestion/{id}/reports/quality`) on top of the existing list and summary endpoints |
| Catalog | [Get Merchant Brands](/retail-media/v2027.01-rc/docs/merchant-brands) — list brands available in a merchant's catalog |
| Creatives | [Search Enriched Creatives](/retail-media/v2027.01-rc/docs/search-enriched-creatives) — find creatives with stable IDs and product collection constraints |

Everything else is unchanged from stable. For all other guides and reference documentation, use the [current stable version](/retail-media/docs/welcome-to-criteo).

---

## How to use this version

Call the API using `2027-01` as the version identifier:

```http
https://api.criteo.com/2027-01/retail-media/...
```

---

## Versioning policy

Release Candidates are production-ready. Only bug fixes are allowed after RC — no breaking changes. See the [Versioning Policy](/criteo-apis/docs/versioning-policy) for the full release lifecycle.
