title: UI/API Metrics Parity
description: Maps Commerce Max (DSP) and Retailer Analytics (SSP) UI metric and dimension labels to their API field names.
---

UI labels and API field names often differ in Retail Media reporting. This page is a lookup: find the label you see in the interface, get the field name to use in your API request. Covers Sponsored Products and Onsite Display only — Offsite is excluded.

`—` means no API field exists for that concept on the current endpoint.

## Cross-surface naming differences

These fields share a concept across DSP and SSP but use different names in each API.

| Concept | DSP API | SSP API |
|---|---|---|
| Attributed sales | `attributedSales` | `sales` |
| Attributed units | `attributedUnits` | `units` |
| Attributed orders | `attributedOrders` | `transactions` |
| Video starts | `videosStarted` | `videoStarts` |
| Product ID | `productId` | `advProductId` |
| Product name | `productName` | `advProductName` |
| Page type | `pageType` | `pageTypeName` |

<Warning>
  **`campaignType` (DSP) and `campaignTypeName` (SSP) are not the same concept.** DSP's `campaignType` (`sponsoredProducts` / `onSiteDisplays`) identifies the ad format. SSP's `campaignTypeName` (`Open Auction` / `Preferred Deals`) identifies the pricing model. Mapping them 1:1 will produce incorrect data.
</Warning>

<Warning>
  **`spend` (DSP) and `workingMedia` (SSP) are not confirmed to be the same value.** Both represent brand-side media cost, but their exact scope differs depending on campaign type and fee structure. Do not assume they reconcile without verifying with Criteo support.
</Warning>

<Note>
  **New to brand lookback window:** The Commerce Max UI displays a 180-day lookback for new-to-brand metrics. The API documentation states 12 months. If you are reconciling new-to-brand numbers between the UI and the API, confirm the active window with Criteo support before drawing conclusions.
</Note>

<Note>
  **SSP ROAS formula:** The Retailer Analytics UI defines ROAS differently depending on the report — `Sales ÷ Net Revenue` on the Revenue report, and `Sales ÷ Spend` on Onsite Sponsored Products and Onsite Display reports. The SSP API's `roas` field uses a single formula (`sales / openAuctionRevenue` or `sales / preferredDealsRevenue`). Verify which denominator matches your use case before reconciling.
</Note>
