---
title: Discover Retailers and Pages
description: Search for retailers available to an account and discover which campaign types, buy types, and page environments each supports.
---

Search for retailers associated with an account and discover which ad formats, page types, and environments they support. Use the response to validate retailer capabilities before creating campaigns or line items.

## Prerequisites

- Authenticated with scope `retail-media:read`
- Account ID (`accountId`) — from your account list

## Steps

### 1. Search retailers

[→ `POST /retail-media/accounts/{accountId}/retailers/search`](/retail-media/reference/search-account-retailers)

Pass an optional `retailerIdFilter` array to narrow results. Omit it (or pass an empty array) to return all retailers accessible to the account.

Results are paginated via `offset` and `limit` query parameters (max `limit` is `10`).

```bash
curl -X POST "https://api.criteo.com/2026-07/retail-media/accounts/4567891234567891/retailers/search?offset=0&limit=10" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "attributes": {
        "retailerIdFilter": []
      }
    }
  }'
```

<Warning>`limit` must be between 1 and 10. A value above 10 returns `400 Model validation error`. Use `offset` pagination to retrieve more than 10 retailers.</Warning>

---

### 2. Read campaign availabilities

Each retailer in `data[].attributes.campaignAvailabilities` lists the `campaignType` × `buyType` combinations available, along with:

- `budgetModelAvailabilities` — which budget models are supported (`criteoBudget`, `retailerBudget`). An empty array means that combination is unavailable at this retailer.
- `validCombinations` — the `pageType` × `pageEnvironmentType` pairs where ads can be delivered.

---

## Verify

A successful response has HTTP `200` with a `data` array. Each entry has an `id` (retailer ID) and a `campaignAvailabilities` array. An empty `validCombinations` array on a `campaignType` × `buyType` entry means that format is not available at this retailer.

---
