Campaigns in Retail Media are structured in three layers: **account → campaign → line item**. Each layer controls a different scope of settings.

| Layer | Controls |
|---|---|
| **Campaign** | Campaign type (Sponsored Products, Onsite Display, Offsite), budget model, retailer scoping |
| **Line item** | Buy type, bid strategy, start/end dates, budget, keyword strategy |
| **Line item sub-resources** | Promoted products, keyword bids, audience/store/add-to-basket targeting |

Before creating a campaign, check which campaign types, buy types, and page environments the target retailer supports — see [Discover Retailers and Pages](/retail-media/docs/retailer-search).

## Create a campaign

[→ `POST /retail-media/accounts/{accountId}/campaigns`](/retail-media/reference/create-campaigns-by-account-id)

## Create a line item

For auction (Sponsored Products / Onsite Display):

[→ `POST /retail-media/campaigns/{campaignId}/auction-line-items`](/retail-media/reference/create-auction-line-item)

For preferred deals or sponsorship:

[→ `POST /retail-media/campaigns/{campaignId}/preferred-line-items`](/retail-media/reference/create-preferred-line-items)

Both campaign and line item creation are synchronous and return the new resource immediately.
