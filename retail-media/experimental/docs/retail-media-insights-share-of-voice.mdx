---
title: Request a Share of Voice Report
description: How to retrieve impression and click share metrics by category or keyword using the Share of Voice async reporting API.
---

This guide covers submitting a Share of Voice report and downloading the results. By the end, you will have a report showing impression and click share across categories or keywords where your ads were served on retailer sites.

---

## Prerequisites

- **Auth scope**: `retail-media:read` — see [Authentication](/retail-media/experimental/docs/authentication)
- **Account ID**: an `accountId` with active onsite campaigns — obtained from [your account list](/retail-media/experimental/reference/gateway/get-me)

---

## Steps

### 1. Submit the Share of Voice request

[→ `POST /retail-media/insights/share-of-voice`](/retail-media/experimental/reference/analytics/create-share-of-voice)

Provide `accountId`, `startDate`, `endDate`, `dimensions`, and `metrics`. All five are required.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/insights/share-of-voice" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "type": "RetailMediaShareOfVoice",
      "attributes": {
        "accountId": "4567891234567891",
        "startDate": "2026-10-01",
        "endDate": "2026-10-31",
        "dimensions": ["date", "campaignName", "retailerId", "servedCategory"],
        "metrics": ["impressions", "clicks"],
        "format": "json-compact"
      }
    }
  }'
```

Save `data.id` from the response — this is the `insightId` used to poll for status.

### 2. Poll for status

[→ `GET /retail-media/insights/{insight-id}/status`](/retail-media/experimental/reference/analytics/get-insight-status)

Poll until `data.attributes.status` is `success`. Retry on `pending`. On `failure`, the request was invalid — do not retry without changing the parameters.

### 3. Download the output

[→ `GET /retail-media/insights/{insight-id}/output`](/retail-media/experimental/reference/analytics/get-insight-output)

Returns the report in the format specified at submission (`json`, `json-compact`, `json-newline`, or `csv`).

---

## Verify

A successful submission returns HTTP `200` with `data.attributes.status: pending` and a `data.id`. After polling to `success`, the output endpoint returns the report data. If `status` is `failure`, resubmit with corrected parameters.

---

## Constraints

| Limit | Value |
|---|---|
| Required fields | `accountId`, `startDate`, `endDate`, `dimensions`, `metrics` |
| `filters.campaignType` | `all`, `onsiteSponsoredProducts`, `onsiteDisplay` |
| Granularity options | Category-level or keyword-level — controlled via `dimensions` |
