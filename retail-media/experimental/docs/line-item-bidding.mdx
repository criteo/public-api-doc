---
title: Configure Line Item Bidding
description: How to retrieve minimum bid guidance and set the maximum bid for Adaptive bidding on a line item.
---

This guide covers checking minimum bid requirements and setting the maximum bid for Adaptive bidding. By the end, you will have a `maxBid` configured on the line item.

<Info>
  This endpoint is available in the **Experimental** Retail Media API only. Supported for both Onsite Display Auction and Sponsored Products Auction line items.
</Info>

---

## Prerequisites

- **Auth scope**: `retail-media:manage` for set, `retail-media:read` for get/min-bid — see [Authentication](/retail-media/experimental/docs/authentication)
- **Line item ID**: an existing `lineItemId` from [Create and Submit a Line Item](/retail-media/experimental/docs/line-items-core)

---

## Steps

### 1. Get minimum bid guidance

[→ `GET /retail-media/line-items/{line-item-id}/min-bid`](/retail-media/experimental/reference/line-item/get-min-bid-by-line-item-id)

Returns the minimum and recommended maximum bid for the line item. The `biddingType` field indicates whether guidance is `CpmBidding` (Display) or `CpcBidding` (Sponsored Products). For CPM line items, `cpmMinBidDetails.minBid` is the inclusive floor and `cpmMinBidDetails.recommendedMinBid` is the recommended value. For CPC line items, `cpcMinBidDetails.minBid` is the floor.

### 2. Set the maximum bid

[→ `POST /retail-media/line-items/{line-item-id}/set-bidding`](/retail-media/experimental/reference/line-item/set-bidding-by-line-item-id)

Set `maxBid` to the ceiling the Adaptive strategy may use. Set to `null` to remove the maximum.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/line-items/112233445566778899/set-bidding" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "type": "LineItemBiddingRequest",
      "attributes": {
        "maxBid": 2.50
      }
    }
  }'
```

### 3. Retrieve current bidding configuration

[→ `GET /retail-media/line-items/{line-item-id}/bidding`](/retail-media/experimental/reference/line-item/get-bidding-by-line-item-id)

Returns the current `maxBid` value for the line item.

---

## Verify

A successful set returns HTTP `200` with `data.attributes.maxBid` matching the value you sent. Inspect `errors` and `warnings` even on `200 OK`.

---

## Constraints

| Limit | Value |
|---|---|
| `maxBid` | number or null — set to null to remove the maximum |
| Minimum bid | `maxBid` must meet or exceed the floor returned by min-bid |
