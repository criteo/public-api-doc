## Overview

The products endpoint lets you add one or more product SKUs to a line item's product pool. The line item will promote the products in the pool when it delivers ads.

Adding a SKU that is already in the product pool is a no-op — no duplicate is created and no error is raised for that SKU.

<Info>
  This endpoint currently supports **Onsite Display Auction** line items only. Requests for line items with a different buy type are rejected with a `501` error.
</Info>

## Endpoints

| Method | Endpoint | Description |
| --- | --- | --- |
| `POST` | `/line-items/{line-item-id}/products` | Add products to a line item's product pool. |

## Add Products to a Line Item

Adds one or more product SKUs to the product pool of an existing line item.

<EndpointBadge method="post">
```http
https://api.criteo.com/experimental/retail-media/line-items/{line-item-id}/products
```
</EndpointBadge>

### Path Parameters

| Parameter | Description |
| --- | --- |
| `line-item-id` | The unique identifier of the line item. |

### Request Attributes

_TODO (R&D): confirm request body shape — expected to be an array of SKU IDs under `data.attributes`. Confirm field name and type._

| Attribute | Required | Type | Description |
| --- | --- | --- | --- |
| `skuIds` | Yes | array of strings | One or more product SKU IDs to add to the line item's product pool. Duplicates within the same request are silently ignored — each SKU is added once. |

**Sample Request**

```json
{
  "data": {
    "type": "line-item-products",
    "attributes": {
      "skuIds": ["SKU-001", "SKU-002", "SKU-003"]
    }
  }
}
```
