---
title: Configure Line Item Targets
description: How to add, update, and remove keyword, page type, and category targets for a line item.
---

This guide covers creating targets that control where and how a line item serves — keywords, page types, and categories. By the end, you will have targeting configured and the targets submitted as part of [line item review](/retail-media/experimental/docs/line-items-core#5-submit-for-retailer-review).

---

## Prerequisites

- **Auth scope**: `retail-media:manage` for create/update/delete, `retail-media:read` for fetch — see [Authentication](/retail-media/experimental/docs/authentication)
- **Line item ID**: an existing `lineItemId` from [Create and Submit a Line Item](/retail-media/experimental/docs/line-items-core)

---

## Steps

### 1. Create targets

[→ `POST /retail-media/line-items/{lineItemId}/targets/create`](/retail-media/experimental/reference/line-item/create-line-item-targets)

Each target needs a `targetType` and a matching details object. Send up to 100 targets per request; you can mix target types in one call.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/line-items/112233445566778899/targets/create" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": [
      {
        "type": "Target",
        "attributes": {
          "targetType": "PageType",
          "negative": false,
          "pageTypeTargetDetails": { "pageType": "Search" }
        }
      },
      {
        "type": "Target",
        "attributes": {
          "targetType": "ManualKeyword",
          "negative": false,
          "bidMultiplier": 1.25,
          "manualKeywordTargetDetails": {
            "keywordInput": "trail running shoes",
            "matchType": "Exact"
          }
        }
      }
    ]
  }'
```

<Warning>
  Create uses partial success by target type — a `200 OK` response can still contain errors for individual targets. Always inspect both `errors` and `warnings` before treating the response as complete.
</Warning>

### 2. Retrieve targets

[→ `GET /retail-media/line-items/{lineItemId}/targets`](/retail-media/experimental/reference/line-item/get-line-item-targets)

Returns all configured targets with their `approvalStatus`. Use the returned resources as input for update or delete operations.

### 3. Update targets

[→ `POST /retail-media/line-items/{lineItemId}/targets/update`](/retail-media/experimental/reference/line-item/update-line-item-targets)

Copy the target resources from a GET response and modify only the mutable fields (`bidMultiplier`, `categoryTargetDetails.includeChildren`). The identity fields (keyword text, match type, page type, category ID, `negative`) cannot be changed — delete and recreate to change them.

### 4. Delete targets

[→ `POST /retail-media/line-items/{lineItemId}/targets/delete`](/retail-media/experimental/reference/line-item/delete-line-item-targets)

Copy the target resources from a GET response without changes and pass them to delete.

<Warning>
  Deleting a PageType target can cascade-remove any Category targets that were attached only to that page type. The response includes a `category-targets-removed-with-page-type` warning when this happens.
</Warning>

---

## Verify

A successful create returns HTTP `200` with the created targets in `data` and an empty `errors` array. Confirm each target's `approvalStatus` — newly created targets start as `Unsubmitted` until submitted for retailer review. After submission, they move to `InReview`.

---

## Constraints

| Limit | Value |
|---|---|
| Max targets per request | 100 |
| `targetType` | `ManualKeyword`, `PageType`, `Category` — `Geography` is supported but not yet documented |
| Bid multipliers | Supported on non-negative targets only |
| ManualKeyword OnsiteDisplay | Only `Exact` match type is supported (not `Broad`) |
| Positive Category targets | Not supported on dynamic-match (`isDynamicMatch: true`) line items — use negative only |
| Identity fields | Cannot be changed via update — delete and recreate to change keyword text, match type, page type, or category ID |
