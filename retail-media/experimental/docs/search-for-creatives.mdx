---
title: Search for Creatives
description: How to search an account's creatives by name, type, brand, template, or page type.
---

Use this endpoint to find creatives available to a line item before associating them. For stable creative IDs that persist across edits and product collection constraints, use [Search Enriched Creatives](/retail-media/experimental/docs/search-enriched-creatives) instead.

---

## Prerequisites

- **Auth scope**: `retail-media:read` — see [Authentication](/retail-media/experimental/docs/authentication)
- **Account ID**: the `accountId` whose creatives to search

---

## Steps

### 1. Search creatives

[→ `POST /retail-media/accounts/{account-id}/creatives/search`](/retail-media/experimental/reference/creative/search-creatives)

All filters are optional. Send `attributes: {}` to return all creatives. Multiple filters are ANDed together.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/accounts/4567891234567891/creatives/search" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "attributes": {
        "CreativeTypes": ["CommerceDisplay", "CommerceVideo"],
        "RetailerIds": ["1141"],
        "PageTypes": ["Search", "Browse"]
      }
    }
  }'
```

Paginate using `offset` and `limit` query parameters (default 50, max 500).

---

## Verify

A successful response returns HTTP `200` with a `data` array and `metadata.count` (total matches). Each creative includes `id`, `name`, `status`, `creativeType`, `pageType`, `brandId`, `lineItems`, and `preview`. An empty `data` array means no creatives match the filters.

---

## Constraints

| Limit | Value |
|---|---|
| Default page size | 50; max 500 |
| `creativeTypes` | `CommerceDisplay`, `CommerceVideo`, `StandardDisplay`, `StandardVideo` (case-insensitive) |
| Filter attribute names | PascalCase in the request body: `CreativeName`, `CreativeIds`, `CreativeTypes`, `BrandIds`, `TemplateIds`, `RetailerIds`, `PageTypes` |
| Stable creative IDs | Creative IDs from this endpoint can change across edits — use [Search Enriched Creatives](/retail-media/experimental/docs/search-enriched-creatives) for IDs stable across versions |
