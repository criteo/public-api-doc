## Overview

Line Item Minimum Bid Details returns the lowest valid bid for a line item. Call it before you set the line item's max bid so you know the minimum you can use. If you set a max bid below this value, the request is rejected.

<Info>
  **Availability: Available**

  This endpoint is available in the Experimental Retail Media API.
</Info>

The endpoint supports Onsite Display and Sponsored Products auction line items. The response depends on the line item's bidding type:

- **Onsite Display** line items bid use CPM bidding.
- **Sponsored Products** line items bid use CPC bidding.

## Endpoint

| Method | Endpoint | Description | Availability |
| --- | --- | --- | --- |
| `GET` | `/retail-media/line-items/{line-item-id}/min-bid` | Retrieve the minimum bid for a line item. | Available |

## Retrieve Line Item Minimum Bid Details

<EndpointBadge method="get">
```http
https://api.criteo.com/experimental/retail-media/line-items/{line-item-id}/min-bid
```
</EndpointBadge>

### Path parameter

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `line-item-id` | string | Yes | Identifier of the Onsite Display or Sponsored Products auction line item. |

The authenticated user must have permission to view the requested line item.

### Sample request

```bash
curl -X GET "https://api.criteo.com/experimental/retail-media/line-items/123456789012345678/min-bid" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Accept: application/json"
```

### Response attributes

All attributes below are nested under `data.attributes` in the response envelope. Amounts are in the line item's currency.

| Attribute | Type | Description |
| --- | --- | --- |
| `biddingType` | string | Bidding type of the line item: `CpmBidding` or `CpcBidding`.|
| `cpmMinBidDetails` | object or null | Minimum bid values for CPM line items. `null` when `biddingType` is `CpcBidding`. |
| `cpmMinBidDetails.minBid` | number | Lowest bid the line item accepts. |
| `cpmMinBidDetails.recommendedMinBid` | number or null | Recommended minimum bid. This is a recommendation, not a requirement. See [How minimum bids are calculated](#how-minimum-bids-are-calculated). |
| `cpcMinBidDetails` | object or null | Minimum bid values for CPC line items. `null` when `biddingType` is `CpmBidding`. |
| `cpcMinBidDetails.minBid` | number | Lowest bid the line item accepts. |

### How minimum bids are calculated

#### Onsite Display (CPM)

The retailer sets CPM rates per page type. The rate for a page type depends on the creative format and the product category. For each page type configured on the line item, the endpoint finds the rates that match the line item's creatives and category targets, then calculates:

- **`minBid`:** The lowest rate across the line item's page types, ignoring rates of `0`. A bid below this value is rejected.
- **`recommendedMinBid`:** The highest rate across the line item's page types. A bid below this value is accepted but returns a warning. A bid at or above it meets the applicable rate for every page type, but doesn't guarantee delivery. Delivery also depends on auction conditions and other line item settings.

If the line item has no page types, `minBid` is `0` and `recommendedMinBid` is `null`.

#### Sponsored Products (CPC)

The retailer sets a minimum CPC bid for each product category. The minimum bid is calculated from the categories of the SKUs on the line item.

- **`minBid`:** The highest minimum bid across the categories of the SKUs on the line item. A bid below this value is rejected.

If the line item has no SKUs, `minBid` is the retailer's default minimum bid.

### Sample responses

An Onsite Display line item:

```json
{
  "data": {
    "type": "LineItemMinBidResponse",
    "attributes": {
      "biddingType": "CpmBidding",
      "cpmMinBidDetails": {
        "minBid": 1.25,
        "recommendedMinBid": 2.00
      },
      "cpcMinBidDetails": null
    }
  },
  "warnings": [],
  "errors": []
}
```

A Sponsored Products line item:

```json
{
  "data": {
    "type": "LineItemMinBidResponse",
    "attributes": {
      "biddingType": "CpcBidding",
      "cpmMinBidDetails": null,
      "cpcMinBidDetails": {
        "minBid": 0.50
      }
    }
  },
  "warnings": [],
  "errors": []
}
```

### Responses

| Status | Code | Description |
| --- | --- | --- |
| `200 OK` | | Returns the minimum bid for the line item. |
| `400 Bad Request` | `unsupported-line-item-type` | The minimum bid is available only for Onsite Display and Sponsored Products auction line items. |
| `400 Bad Request` | `unsupported-bid-strategy` | The minimum bid is available only for line items that use Adaptive bidding. |
| `400 Bad Request` | `minimum-bid-guidance-requires-creative` | An Onsite Display line item must have at least one creative. |
| `401 Unauthorized` | `unauthorized` | The caller is not authenticated. |
| `403 Forbidden` | `forbidden` | The caller does not have access to the requested line item. |
| `500 Internal Server Error` | `internal-error` | The minimum bid could not be calculated, usually because a dependent service failed. Retry the request. If the failure persists, contact support. |
