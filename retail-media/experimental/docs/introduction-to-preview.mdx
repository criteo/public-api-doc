## Experimental version

The experimental version lets you explore brand-new features before they are finalized, so you can plan ahead and provide early feedback.

New features may appear in the experimental version at any time and may change significantly before — or without ever — reaching a stable release.

This version can be called using "experimental" as the version identifier:

```http
https://api.criteo.com/experimental
```

<Info>
  For more details, visit our [Versioning policy](https://developers.criteo.com/criteo-apis/docs/versioning-policy) page.
</Info>

**Experimental — For early exploration**

- Test brand-new features before they're finalized
- Contracts may change significantly at any time
- Not suitable for production use

For the stable endpoints and other detailed documentation, see the [current Criteo API version](/retail-media/docs/welcome-to-criteo).
