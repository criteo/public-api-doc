---
title: Manage Campaigns
description: How to create, update, and search campaigns using the experimental Campaigns API.
---

This guide covers creating a campaign, updating its budget or flight dates, and searching campaigns under an account. By the end, you will have a campaign ready to attach line items to.

<Info>
  This endpoint is available in the **Experimental** Retail Media API only.
</Info>

---

## Prerequisites

- **Auth scope**: `retail-media:manage` for create/update, `retail-media:read` for fetch/search — see [Authentication](/retail-media/experimental/docs/authentication)
- **Account ID**: the `accountId` that will own the campaign
- **Balance IDs** *(optional)*: balance IDs to draw budget from — invalid or inaccessible IDs cause the entire create request to fail

---

## Steps

### 1. Create a campaign

[→ `POST /retail-media/accounts/{account-id}/campaigns`](/retail-media/experimental/reference/campaign/create-campaign)

Provide `name`, `campaignType`, `buyType`, `objective`, `budgetDetails.amount`, and `scheduleDetails`. `campaignType`, `buyType`, `objective`, `regulatedCategory`, and `billByRetailerId` are set only on creation and cannot be changed later.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/accounts/4567891234567891/campaigns" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "type": "CampaignCreateModel",
      "attributes": {
        "name": "Back-to-school sponsored products",
        "campaignType": "SponsoredProducts",
        "buyType": "Auction",
        "objective": "Conversion",
        "budgetDetails": { "amount": 5000 },
        "scheduleDetails": {
          "startDate": "2026-11-02T00:00:00Z",
          "endDate": "2026-12-31T00:00:00Z"
        },
        "drawableBalanceIds": ["1122"]
      }
    }
  }'
```

Save `data.id` from the response — this is the `campaignId` used to create line items and for future updates.

<Warning>
  `objective` must be compatible with `campaignType`: `SponsoredProducts` accepts `Clicks`, `Conversion`, `Revenue`; `OnsiteDisplay` accepts `Impressions` only. A mismatch returns `invalid-objective-campaign-type`.
</Warning>

### 2. Update a campaign

[→ `PATCH /retail-media/campaigns/{campaign-id}`](/retail-media/experimental/reference/campaign/update-campaign)

Include only the fields to change — omitted fields are left unchanged. To clear `companyName` or `onBehalfCompanyName`, send `{ "value": null }` explicitly; omitting the field leaves the stored value unchanged.

### 3. Fetch a campaign

[→ `GET /retail-media/campaigns/{campaign-id}`](/retail-media/experimental/reference/campaign/get-campaign)

Returns the current campaign state including `budgetDetails.spent`, `budgetDetails.remaining`, and `status`.

### 4. Search campaigns

[→ `POST /retail-media/accounts/{account-id}/campaigns/search`](/retail-media/experimental/reference/campaign/search-campaigns)

Filter by `campaignIdFilter`, `campaignTypeFilter`, `buyTypeFilter`, or `campaignStatusFilter`. Paginate with `limit` (max 500) and `offset` (max `offset + limit` = 10,000).

---

## Verify

A successful create returns HTTP `201` with the new campaign `id` in `data.id`. Confirm `data.attributes.status` is `Inactive` (campaigns start inactive until a line item activates them). The budget figures in search results may lag — use the fetch endpoint for current `spent` and `remaining` values.

---

## Constraints

| Limit | Value |
|---|---|
| `campaignType` | `SponsoredProducts`, `OnsiteDisplay` — immutable after creation |
| `objective` | `SponsoredProducts`: `Clicks`, `Conversion`, `Revenue` — `OnsiteDisplay`: `Impressions` |
| `endDate` | Cannot be `9999-12-30T00:00:00Z` for dynamic objectives |
| `name` | 1–255 characters, unique within the account |
| `budgetDetails.memo` | Up to 250 characters |
| `companyName` / `onBehalfCompanyName` | EU DSA fields, supply accounts only, max 255 characters |
| Search page size | 1–500 (default 25), `offset + limit` ≤ 10,000 |
| `drawableBalanceIds` | Always empty in search results — fetch the campaign to retrieve them |
