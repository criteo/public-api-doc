## Overview

A campaign groups line items that share attribution settings, flight dates and budget.

`campaignType` is a required discriminator. The fields are the same for both types. Some accept type-specific values.

| `objective` | `SponsoredProducts` | `OnsiteDisplay` |
| --- | :---: | :---: |
| `Clicks` | Yes | - |
| `Conversion` | Yes | - |
| `Revenue` | Yes | - |
| `Impressions` | - | Yes |

An objective the campaign type does not accept returns `invalid-objective-campaign-type`.

## Prerequisites

Before calling these endpoints, ensure the following are in place:

- **Authentication**: a valid access token. See [Authentication](/retail-media/experimental/docs/authentication).
- **App permissions**: the `RetailMedia_Campaign_Manage` scope to create and update, and `RetailMedia_Campaign_Read` to fetch and search. See [App Scopes](/retail-media/experimental/docs/app-scopes).

## Endpoints

| Method | Endpoint | Description |
| --- | --- | --- |
| `POST` | `/accounts/{account-id}/campaigns` | Create a campaign. |

| `PATCH` | `/campaigns/{campaign-id}` | Update a campaign. |
| `POST` | `/accounts/{account-id}/campaigns/search` | Search campaigns under an account. |

## Create a Campaign

<EndpointBadge method="post">
```http
https://api.criteo.com/experimental/retail-media/accounts/{account-id}/campaigns
```
</EndpointBadge>

### Path Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `account-id` | string | Yes | Identifier of the account that owns the campaign. |

### Request Attributes

All attributes below are nested under `data.attributes`. The resource `type` is `CampaignCreateModel`.

| Attribute | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Unique within the account. 1 to 255 characters. |
| `campaignType` | string | Yes | `SponsoredProducts` or `OnsiteDisplay`. Set only on creation. |
| `buyType` | string | Yes | `Auction`. Set only on creation. |
| `objective` | string | Yes | See [Overview](#overview). Set only on creation. |
| `budgetDetails.amount` | number | Yes | Total the campaign may spend over its flight. Greater than 0. |
| `scheduleDetails.startDate` | string | Yes | Flight start, as a date-time. |
| `scheduleDetails.endDate` | string | Yes | Flight end, as a date-time. Not before `startDate`. `9999-12-30T00:00:00Z` is rejected. |
| `attributionSettings.clickAttributionWindow` | string | No | `OneWeek`, `TwoWeeks` or `OneMonth`. Default: `OneMonth` for `SponsoredProducts`, `TwoWeeks` for `OnsiteDisplay`. |
| `attributionSettings.viewAttributionWindow` | string | No | `None`, `OneDay`, `OneWeek`, `TwoWeeks` or `OneMonth`. Default: `OneDay` for `SponsoredProducts`, `TwoWeeks` for `OnsiteDisplay`. Not longer than the click window. |
| `attributionSettings.clickAttributionScope` | string | No | `SameSku`, `SameSkuCategory` or `SameSkuCategoryBrand`. Default: `SameSkuCategory`. |
| `attributionSettings.viewAttributionScope` | string | No | `SameSku`, `SameSkuCategory` or `SameSkuCategoryBrand`. Default: `SameSku` for `SponsoredProducts`, `SameSkuCategory` for `OnsiteDisplay`. Not broader than the click scope. |
| `regulatedCategory` | string | No | `None` or `Alcohol`. Default: `None`. Set only on creation. |
| `drawableBalanceIds` | array of strings | No | Balances the campaign draws from. |
| `billByRetailerId` | string | No | Retailer billed. Set only on creation. |
| `companyName` | string | No | EU DSA. Up to 255 characters. Supply accounts only. |
| `onBehalfCompanyName` | string | No | EU DSA. Up to 255 characters. Supply accounts only. |

An unknown or inaccessible balance in `drawableBalanceIds` fails the request and no campaign is kept.

**Sample Request**

```bash
curl -L -X POST 'https://api.criteo.com/experimental/retail-media/accounts/12345/campaigns' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <MY_ACCESS_TOKEN>' \
  -d '{
    "data": {
      "type": "CampaignCreateModel",
      "attributes": {
        "name": "Back-to-school sponsored products",
        "campaignType": "SponsoredProducts",
        "buyType": "Auction",
        "objective": "Conversion",
        "budgetDetails": { "amount": 5000 },
        "scheduleDetails": {
          "startDate": "2026-11-02T00:00:00Z",
          "endDate": "2026-12-31T00:00:00Z"
        },
        "drawableBalanceIds": ["1122"]
      }
    }
  }'
```

### Response Attributes

The response is a `CampaignResponseModel`. See [Get a Campaign](#get-a-campaign) for the attributes.
The budget is the stored one: `spent` is `0` and `remaining` equals `amount`.

## Get a Campaign

<EndpointBadge method="get">
```http
https://api.criteo.com/experimental/retail-media/campaigns/{campaign-id}
```
</EndpointBadge>

### Path Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `campaign-id` | string | Yes | Identifier of the campaign to retrieve. |

### Response Attributes

All attributes below are nested under `data.attributes`.

| Attribute | Type | Description |
| --- | --- | --- |
| `id` | string | Campaign identifier. |
| `accountId` | string | Account that owns the campaign. |
| `name` | string | Campaign name. |
| `status` | string | `Active` when at least one line item is active, otherwise `Inactive`. |
| `campaignType` | string | `SponsoredProducts` or `OnsiteDisplay`. |
| `buyType` | string | `Auction`, `PreferredDeals` or `Sponsorship`. |
| `objective` | string | `Clicks`, `Conversion`, `Revenue` or `Impressions`. |
| `budgetDetails.amount` | number or null | Total the campaign may spend over its flight. Null when uncapped. |
| `budgetDetails.spent` | number | Amount spent so far. |
| `budgetDetails.remaining` | number or null | Amount left under the cap. Null when uncapped. |
| `budgetDetails.memo` | string or null | Note from the latest budget change. |
| `budgetDetails.cappings` | array | Per-period ceilings. Only capped periods are reported. |
| `budgetDetails.pacing.type` | string | `None` or `Automatic`. |
| `budgetDetails.status` | string | Which cap stops spending: `BudgetAvailable`, `DailyBudgetReached`, `MonthlyBudgetReached` or `TotalBudgetReached`. Omitted when unknown. |
| `scheduleDetails.startDate` | string | Flight start. |
| `scheduleDetails.endDate` | string | Flight end. |
| `attributionSettings` | object | The four attribution settings. |
| `regulatedCategory` | string | `None` or `Alcohol`. |
| `drawableBalanceIds` | array of strings | Balances the campaign draws from. |
| `billByRetailerId` | string or null | Retailer billed. |
| `companyName` | string or null | EU DSA. |
| `onBehalfCompanyName` | string or null | EU DSA. |
| `createdAt` | string | Creation time, UTC. |
| `updatedAt` | string | Last update time, UTC. |

## Update a Campaign

<EndpointBadge method="patch">
```http
https://api.criteo.com/experimental/retail-media/campaigns/{campaign-id}
```
</EndpointBadge>

PATCH is partial: include only the fields you want to change. Omitted fields are left unchanged.
A request without fields succeeds and returns the campaign as stored.

### Path Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `campaign-id` | string | Yes | Identifier of the campaign to update. |

### Request Attributes

All attributes below are nested under `data.attributes`. The resource `type` is `CampaignUpdateModel`.

| Attribute | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | No | Unique within the account. 1 to 255 characters. |
| `budgetDetails.amount` | number | Required with `budgetDetails` | New total. Greater than 0. |
| `budgetDetails.memo` | string | No | Note for the change. Up to 250 characters. An omitted memo clears the stored one. |
| `scheduleDetails.startDate` | string | Required with `scheduleDetails` | New flight start. |
| `scheduleDetails.endDate` | string | Required with `scheduleDetails` | New flight end. `9999-12-30T00:00:00Z` is rejected. |
| `attributionSettings` | object | No | Same fields as on creation. Omitted fields are unchanged. The rules apply to the merged result. |
| `companyName` | object | No | `{ "value": "..." }` to set, `{ "value": null }` to clear. Supply accounts only. |
| `onBehalfCompanyName` | object | No | Same as `companyName`. |

`campaignType`, `buyType`, `objective`, `regulatedCategory`, `billByRetailerId` and `drawableBalanceIds` are set only on creation and are ignored here.
`budgetDetails` and `scheduleDetails` sent as `null` leave the stored values unchanged.
An archived campaign cannot be updated.

**Sample Request**

```bash
curl -L -X PATCH 'https://api.criteo.com/experimental/retail-media/campaigns/987654321' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <MY_ACCESS_TOKEN>' \
  -d '{
    "data": {
      "type": "CampaignUpdateModel",
      "attributes": {
        "name": "Back-to-school sponsored products v2",
        "budgetDetails": { "amount": 8000, "memo": "Raised for peak week" }
      }
    }
  }'
```

### Response Attributes

## Search Campaigns

<EndpointBadge method="post">
```http
https://api.criteo.com/experimental/retail-media/accounts/{account-id}/campaigns/search
```
</EndpointBadge>

All filters are optional. Values within a filter are ORed. Distinct filters are ANDed.

### Path Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `account-id` | string | Yes | Identifier of the account to search within. |

### Request Attributes

All attributes below are nested under `data.attributes`. The resource `type` is `CampaignSearchModel`.

| Attribute | Type | Required | Description |
| --- | --- | --- | --- |
| `campaignIdFilter` | array of strings | No | Numeric campaign identifiers. |
| `campaignTypeFilter` | array of strings | No | `SponsoredProducts`, `OnsiteDisplay`. |
| `buyTypeFilter` | array of strings | No | `Auction`, `PreferredDeals`, `Sponsorship`. |
| `campaignStatusFilter` | array of strings | No | `Active`, `Inactive`. |
| `limit` | integer | No | Page size. 1 to 500. Default: 25. |
| `offset` | integer | No | Matches to skip. Default: 0. `offset + limit` cannot exceed 10000. |

**Sample Request**

```bash
curl -L -X POST 'https://api.criteo.com/experimental/retail-media/accounts/12345/campaigns/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <MY_ACCESS_TOKEN>' \
  -d '{
    "data": {
      "type": "CampaignSearchModel",
      "attributes": {
        "campaignTypeFilter": ["SponsoredProducts"],
        "campaignStatusFilter": ["Active"],
        "limit": 25,
        "offset": 0
      }
    }
  }'
```

### Response Attributes

`data` is an array of `CampaignResponseModel`. See [Get a Campaign](#get-a-campaign) for the attributes.

| Attribute | Type | Description |
| --- | --- | --- |
| `metadata.count` | integer | Total matches across all pages. |
| `metadata.limit` | integer | Page size applied. |
| `metadata.offset` | integer | Offset applied. |

## Known Limitations

- Search `budgetDetails` comes from a search index and lag a campaign that has just changed. Fetch the campaign for current figures.
- `drawableBalanceIds` is always empty in search results.
- The update response does not include `drawableBalanceIds`.
