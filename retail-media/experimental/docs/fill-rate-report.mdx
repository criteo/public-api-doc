---
title: Analyze Fill Rate
description: Supply-side fill rate reporting for retailers using the experimental API.
---

Measures how many ad placements were successfully filled versus the total number of delivered placements. Use this to identify supply/demand gaps by placement, page type, category, or ad server.

---

## Prerequisites

- **Auth scope**: `retail-media:read` — see [Authentication](/retail-media/experimental/docs/authentication)
- **Supply account ID**: a `supplyAccountId` for the retailer account

The endpoint is asynchronous: submit a request, poll for status, then download the output.

---

## Steps

### 1. Submit the fill rate request

[→ `POST /retail-media/reports/fillrate`](/retail-media/experimental/reference/analytics/generate-fill-rate-report)

Provide `supplyAccountIds`, `startDate`, `endDate`, `dimensions`, and `metrics`. Use `adServerType` to filter by ad server: `all`, `gam`, or `criteo`. Defaults to `all` if omitted.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/reports/fillrate" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "attributes": {
        "supplyAccountIds": ["4567891234567891"],
        "startDate": "2026-10-01",
        "endDate": "2026-10-31",
        "metrics": ["fillRate", "filledImpressions", "unfilledImpressions"],
        "dimensions": ["date", "pageType"]
      }
    }
  }'
```

Save `data.id` from the response — this is the `reportId` for the next steps.

### 2. Poll for status

[→ `GET /retail-media/reports/{reportId}/status`](/retail-media/experimental/reference/analytics/get-report-status)

Poll until `data.attributes.status` is `success`. Retry on `pending` or `running`. On `failure`, resubmit with corrected parameters.

### 3. Download the output

[→ `GET /retail-media/reports/{reportId}/output`](/retail-media/experimental/reference/analytics/get-report-output)

---

## Verify

A successful submission returns HTTP `200` with a `data.id`. After polling to `success`, the output endpoint returns the fill rate data. If the output is empty, no data exists for the requested date range and supply account.

---

## Constraints

| Limit | Value |
|---|---|
| Max date range | 100 days |
| `adServerType` | `all` (default), `gam`, `criteo` |
