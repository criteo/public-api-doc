---
title: Manage Line Item Creatives
description: How to associate, update, and remove creatives from an Onsite Display Auction line item.
---

This guide covers linking creatives and their product collections to a line item, and removing them. By the end, creatives will be associated and submitted as part of [line item review](/retail-media/experimental/docs/line-items-core#5-submit-for-retailer-review).

---

## Prerequisites

- **Auth scope**: `retail-media:manage` for upsert/delete, `retail-media:read` for fetch — see [Authentication](/retail-media/experimental/docs/authentication)
- **Line item ID**: an existing OnsiteDisplay Auction `lineItemId` from [Create and Submit a Line Item](/retail-media/experimental/docs/line-items-core)
- **Creative IDs**: creatives accessible to the line item's account and retailer — from [Search for Creatives](/retail-media/experimental/docs/search-for-creatives)

---

## Steps

### 1. Associate creatives

[→ `POST /retail-media/line-items/{line-item-id}/creatives/upsert`](/retail-media/experimental/reference/line-item/upsert-line-item-creatives)

Provide `creativeType: AuctionCreative` and an array of `auctionCreativeDetails.lineItemCreatives`. Each entry needs a `creative.id` and a `creativeProductCollections` array — send an empty array when using Dynamic Match.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/line-items/112233445566778899/creatives/upsert" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "type": "UpsertLineItemCreativesInput",
      "attributes": {
        "creativeType": "AuctionCreative",
        "auctionCreativeDetails": {
          "lineItemCreatives": [
            {
              "creative": { "id": "creative-123" },
              "creativeProductCollections": [
                {
                  "isMandatory": false,
                  "products": [
                    { "id": "sku-12345" },
                    { "id": "sku-67890" }
                  ]
                }
              ]
            }
          ]
        }
      }
    }
  }'
```

<Warning>
  Products listed in `creativeProductCollections` are automatically added to the line item's product pool if not already present — subject to the same catalog validation as [adding products directly](/retail-media/experimental/docs/line-item-products). The `creativeProductCollections` array **replaces** the existing collections for each creative on every upsert call.
</Warning>

### 2. Fetch line item creatives

[→ `GET /retail-media/line-items/{line-item-id}/creatives`](/retail-media/experimental/reference/line-item/get-line-item-creatives)

Returns all associated creatives with their `approvalStatus` and product collections. The same `creative.id` may appear twice when both an approved and a proposed revision are associated — use `creative.modifiedAt` to distinguish them.

### 3. Remove creatives

[→ `POST /retail-media/line-items/{line-item-id}/creatives/delete`](/retail-media/experimental/reference/line-item/delete-line-item-creatives)

Pass up to 20 `creativeIds`. Removing a creative disassociates it from the line item — it does not delete the creative resource. IDs not associated with the line item generate an `unmatched-creative-id` warning but the request still removes matched IDs.

---

## Verify

A successful upsert returns HTTP `200` with the associated creatives in `auctionCreativeDetails.lineItemCreatives` and their `approvalStatus: Unsubmitted`. After retailer approval, `approvalStatus` becomes `Approved`. A successful delete returns HTTP `200` — use a fetch to confirm the resulting state.

---

## Constraints

| Limit | Value |
|---|---|
| Max creatives per line item | 20 |
| `creativeType` | `AuctionCreative` only — must match the line item buy type |
| Media type | All creatives on a line item must share the same media type (`Display` or `Video`) |
| Upsert behavior | Updates existing association if `creative.id` already linked; does not duplicate |
| Product collections | The supplied array replaces existing collections per creative — not appended |
