---
title: Create and Submit a Line Item
description: How to create, configure, update, and submit a line item for retailer review using the unified Line Item Core API.
---

This guide covers creating a line item under a campaign, updating its settings, and submitting it for retailer review before it can serve ads. By the end, you will have a line item in review status ready to go live once approved.

---

## Prerequisites

- **Auth scope**: `retail-media:manage` — see [Authentication](/retail-media/experimental/docs/authentication)
- **Campaign ID**: an existing campaign ID (`SponsoredProducts Auction` or `OnsiteDisplay Auction` with automatic budgets)
- **Retailer ID**: must match the campaign's retailer if one is set
- Before submitting: at least one product, one creative, and one page type must be configured on the line item

---

## Steps

### 1. Create a line item

[→ `POST /retail-media/line-items`](/retail-media/experimental/reference/line-item/create-line-item)

Provide `name`, `retailerId`, and `campaignId`. The line item inherits its flight dates from the campaign schedule. For OnsiteDisplay, include `onsiteDisplayDetails`; omit it for SponsoredProducts.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/line-items" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "type": "line-item",
      "attributes": {
        "name": "Back-to-school display",
        "retailerId": "1141",
        "campaignId": "987654321",
        "serveToOptOutUser": false,
        "onsiteDisplayDetails": {
          "isPaused": false,
          "auctionDetails": {
            "isDynamicMatch": true
          }
        }
      }
    }
  }'
```

Save `data.id` from the response — this is the `lineItemId` used in all subsequent calls.

<Warning>
  If default budgets fail to set up after creation, the line item is renamed with a `[FAILED]` prefix and returns a budget error. Do not configure a `[FAILED]` line item further — delete and recreate it.
</Warning>

### 2. Configure targets, products, and creatives

Add targeting, products, and creatives to the line item before submitting. See:
- [Configure Line Item Targets](/retail-media/experimental/docs/line-item-targets)
- [Manage Line Item Products](/retail-media/experimental/docs/line-item-products)
- [Manage Line Item Creatives](/retail-media/experimental/docs/line-item-creatives)

### 3. Update the line item

[→ `PATCH /retail-media/line-items/{lineItemId}`](/retail-media/experimental/reference/line-item/update-line-item)

PATCH is partial — include only the fields to change. `campaignId` and `retailerId` cannot be changed after creation.

### 4. Retrieve the full line item view

[→ `GET /retail-media/line-items/{lineItemId}`](/retail-media/experimental/reference/line-item/get-line-item)

Returns a consolidated view including `core`, `targeting`, `adContent`, and `bidding`. Inspect the top-level `warnings` array even on `200 OK` — a dependency failure sets the affected attribute to `null` and adds a warning rather than failing the whole request.

### 5. Submit for retailer review

[→ `POST /retail-media/line-items/{lineItemId}/submit`](/retail-media/experimental/reference/line-item/submit-line-item)

Sends the line item's reviewable configuration (keywords, categories, products, creatives) to the retailer's Line Item Review Center. Include an optional `comment` to give the retailer context.

After submission, reviewable fields show status `In Review`. The retailer approves or rejects them. Only approved line items can serve ads.

---

## Verify

A successful create returns HTTP `200` with the new `lineItemId` in `data.id`. A successful submit returns HTTP `204` with no body. After submission, `data.attributes.core` from a GET will reflect the pending approval status on each reviewable field.

---

## Constraints

| Limit | Value |
|---|---|
| `campaignId`, `retailerId` | Immutable after creation |
| `isDynamicMatch` | Cannot revert from `true` to `false`; cannot change once the line item is approved |
| Submit requirements | At least one product, one creative, and one page type must be configured |
| `name` | 2–255 characters after trimming, unique within the campaign |
| `onsiteDisplayDetails` | OnsiteDisplay campaigns only — omit for SponsoredProducts |
