---
title: Search Line Items
description: How to retrieve line items in bulk from demand or supply accounts using the experimental Line Item Search API.
---

This guide covers searching for line items across accounts — from either a demand or supply perspective. By the end, you will have a paginated list of line items with their core fields and budget status.

---

## Prerequisites

- **Auth scope**: `retail-media:read` — see [Authentication](/retail-media/experimental/docs/authentication)
- **Account ID**: a demand `accountId` for demand search, or a `supplyAccountId` + `retailerIds` for supply search

---

## Steps

### 1. Search line items from a demand account

[→ `POST /retail-media/line-items/demand-search`](/retail-media/experimental/reference/line-item/demand-search-line-items)

Provide one or more `accountIds`. Optionally filter by `campaignIds` or `lineItemIds` (up to 1,000 each). Set `includeChildrenAccounts: true` to include sub-accounts.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/line-items/demand-search" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "type": "DemandSearch",
      "attributes": {
        "accountIds": ["4567891234567891"],
        "campaignIds": ["987654321"],
        "limit": 50,
        "offset": 0
      }
    }
  }'
```

### 2. Search line items from a supply account

[→ `POST /retail-media/line-items/supply-search`](/retail-media/experimental/reference/line-item/supply-search-line-items)

Provide `supplyAccountId` and at least one `retailerId`. Optionally filter by `relationship` to scope results to a specific supply relationship type.

---

## Verify

A successful response returns HTTP `200` with a `data` array and a `metadata` object containing `count` (total matches), `limit`, and `offset`. Each item includes `lineItemId`, `name`, `lineItemType`, `budgetStatus`, `isPaused`, and `flightDates`.

---

## Constraints

| Limit | Value |
|---|---|
| Max `campaignIds` / `lineItemIds` / `retailerIds` per request | 1,000 each |
| Max page size (`limit`) | 10,000 |
| `relationship` values | `Direct`, `PrivateMarket`, `Network`, `AnyIndirect` |
| Supply search | `retailerIds` is required — at least one must be provided |
