---
title: Get Budget Capout History
description: How to retrieve the timestamps when line items hit their budget cap in the past 3 days.
---

Retrieves "Budget Hit" events — when a line item's budget was fully consumed — over the past 3 days. Use this to diagnose pacing issues, over-delivery patterns, or validate campaign strategy effectiveness.

---

## Prerequisites

- **Auth scope**: `retail-media:manage` — see [Authentication](/retail-media/experimental/docs/authentication)
- **Account ID**: the `accountId` that owns the line items
- **Line item IDs**: up to 50 auction line item IDs

---

## Steps

### 1. Request capout history

[→ `POST /retail-media/accounts/{account-id}/line-items/cap-out-history`](/retail-media/experimental/reference/line-item/get-line-item-capout-history)

Provide `lineItemIds` and `budgetTypes`. You can request multiple budget types in a single call.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/accounts/4567891234567891/line-items/cap-out-history" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "type": "LineItemCapoutHistory",
      "attributes": {
        "lineItemIds": ["112233445566778899"],
        "budgetTypes": ["Daily", "Monthly"]
      }
    }
  }'
```

---

## Verify

A successful response returns HTTP `200` with `data.attributes.lineItemBudgetCapOutHistories`. Each entry includes `lineItemId` and `capoutTimes`, with keys for each requested budget type (e.g., `capoutTimes.daily`). If a line item had no capout events in the window for a given budget type, that entry is simply absent from the response.

<Warning>
  `capoutTimes` keys are **lowercase** (`daily`, `hourly`, `monthly`, `total`). A prior breaking change reverted them from PascalCase in October 2026 — update any code that reads these keys.
</Warning>

---

## Constraints

| Limit | Value |
|---|---|
| Max line items per request | 50 |
| Lookback window | 3 days |
| `budgetTypes` | `Total`, `Daily`, `Monthly`, `Hourly` (case-insensitive) |
| `Hourly` | Display line items only — not applicable to Sponsored Products |
| `Daily`, `Monthly` | Sponsored Products line items — returns the most recent 3 events within the window |
| Partial results | If no capout data exists for a budget type or line item, that entry is omitted (not an error) |
