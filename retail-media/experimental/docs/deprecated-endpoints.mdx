title: Deprecated Endpoints
description: Endpoints removed from the Retail Media experimental API, with decommission dates.
---

This page lists endpoints that have been permanently removed from the Retail Media experimental API. Calling a removed endpoint returns `410 Gone`.

<Info>
  The experimental API is a sandbox for features under active development. Endpoints can be removed at any time without a deprecation window. Check the [Changelog](/retail-media/changelog) for a full history of changes.
</Info>

***

## Product buttons

**Removed: October 14, 2026**

| Method | Endpoint |
| ------ | -------- |
| `GET` | `/experimental/retail-media/line-items/{lineItemId}/product-buttons` |
| `POST` | `/experimental/retail-media/line-items/{lineItemId}/product-buttons/create` |
| `GET` | `/experimental/retail-media/line-items/{lineItemId}/product-buttons/{productButtonId}` |
| `PUT` | `/experimental/retail-media/line-items/{lineItemId}/product-buttons/{productButtonId}` |
| `DELETE` | `/experimental/retail-media/line-items/{lineItemId}/product-buttons/{productButtonId}` |
