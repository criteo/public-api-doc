---
title: Manage Audiences
description: How to create, update, and delete audiences for campaign targeting using the experimental Audiences API.
---

This guide covers creating audiences from segment combinations, updating their definitions, and deleting them. By the end, you will have a reusable audience ready to assign to a line item for targeting.

<Warning>
  Your app must have the **Audiences Manage** permission enabled to use these endpoints.
</Warning>

---

## Prerequisites

- **Auth scope**: `retail-media:manage` — see [Authentication](/retail-media/experimental/docs/authentication)
- **Account ID**: the `accountId` that owns the audiences
- **Audience segment IDs**: one or more segment IDs to combine into an audience — from your segment list

---

## Steps

### 1. Create an audience

[→ `POST /retail-media/accounts/{account-id}/audiences/create`](/retail-media/experimental/reference/audience/create-audience)

Provide `name`, `retailerId`, and an `algebra` object combining one or more `audienceSegmentId` values using `and`, `or`, and `not` operators.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/accounts/4567891234567891/audiences/create" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": [
      {
        "attributes": {
          "name": "Recent visitors not in CRM list",
          "retailerId": "1141",
          "algebra": {
            "and": [
              {
                "or": [
                  { "audienceSegmentId": "738406687217913856" },
                  { "audienceSegmentId": "738406688413290496" }
                ]
              },
              {
                "not": { "audienceSegmentId": "735693505849913344" }
              }
            ]
          }
        }
      }
    ]
  }'
```

Save `data[].id` from the response — these are the audience IDs used in targeting and future updates.

<Warning>
  Audience updates are processed at **0h UTC and 12h UTC** and can take up to 5 hours to reflect on a live campaign. Plan segment changes accordingly.
</Warning>

### 2. Update an audience

[→ `PATCH /retail-media/accounts/{account-id}/audiences`](/retail-media/experimental/reference/audience/update-audience)

Provide the audience `id` and updated `algebra` or `name`. Only the fields you include are updated.

### 3. Delete audiences

[→ `POST /retail-media/accounts/{account-id}/audiences/delete`](/retail-media/experimental/reference/audience/delete-audience)

Pass an array of audience IDs to delete in bulk.

---

## Verify

A successful create returns HTTP `200` with the new audience IDs in `data[].id`. Confirm `data[].attributes.status` reflects the expected state. If targeting doesn't update immediately, wait for the next processing window (0h or 12h UTC).

---

## Constraints

| Limit | Value |
|---|---|
| Processing delay | Up to 5 hours after the 0h or 12h UTC processing window |
| Algebra operators | `and`, `or`, `not` — nest freely to combine segment IDs |
