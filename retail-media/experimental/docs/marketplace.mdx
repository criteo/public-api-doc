---
title: Update Product Catalog Data
description: How to update buy box winners and offer prices and availability for a retailer's product catalog.
---

Use these endpoints to keep your catalog current by updating which offer wins the buy box and synchronizing price and availability with your product detail pages.

<Note>
  These endpoints are **asynchronous** — a success response means the request was accepted, not completed.
</Note>

---

## Prerequisites

- **Auth scope**: `retail-media:manage` — see [Authentication](/retail-media/experimental/docs/authentication)
- **Retailer ID**: the `retailer-id` whose catalog to update
- **Regional URL**: use the endpoint matching your region — `api.us.criteo.com` (Americas), `api.as.criteo.com` (APAC), `api.eu.criteo.com` (EMEA)

---

## Steps

### 1. Set the buy box winner

[→ `POST /retail-media/retailers/{retailer-id}/products/set-buy-box-winners`](/retail-media/experimental/reference/catalog/set-buy-box-winners)

Send the offer ID of the new buy box winner. The previous winner for each product becomes a loser automatically.

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/retailers/1141/products/set-buy-box-winners" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "type": "SetProductBuyBoxWinnersRequest",
      "attributes": {
        "productBuyBoxWinners": [
          { "offerId": "offer-123" },
          { "offerId": "offer-456" }
        ]
      }
    }
  }'
```

### 2. Update offer price and availability

[→ `POST /retail-media/retailers/{retailer-id}/offers/update`](/retail-media/experimental/reference/catalog/update-offers)

Provide `offerId`, `price`, and `availability` for each offer. This replaces both values — partial updates are not supported.

---

## Verify

A successful response returns HTTP `200` with empty `warnings` and `errors` arrays. This confirms the request was accepted. The catalog update may take time to propagate — allow up to one hour.

---

## Constraints

| Limit | Value |
|---|---|
| Max buy box winners per request | 5,000 |
| Max offer updates per request | 5,000 |
| `availability` values | `inStock`, `outOfStock`, `preOrder`, `backOrder` |
| Regional URLs | Americas: `api.us.criteo.com` · APAC: `api.as.criteo.com` · EMEA: `api.eu.criteo.com` |
| Duplicate `offerId` in one request | Returns `duplicate-offer-id` error |
