Onsite Display line items sit within a Display campaign and define where and how ads serve — including the retailer, flight dates, and delivery settings.

<Warning>
  **This is a legacy endpoint.** For new integrations, use the unified equivalents: [Line Item Core](/retail-media/experimental/docs/line-items-core) for create and update, [Line Item Targets](/retail-media/experimental/docs/line-item-targets) for targeting, and [Line Item Creatives](/retail-media/experimental/docs/line-item-creatives) for creative assignment.
</Warning>
