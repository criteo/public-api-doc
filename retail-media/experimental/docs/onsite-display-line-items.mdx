---
title: Onsite Display
description: Onsite Display line items control how auction-based display ads deliver across retailer inventory.
---

Onsite Display line items sit within a Display campaign and define where and how ads serve — including the retailer, flight dates, and delivery settings.

Use [Line Item Core](/retail-media/experimental/docs/line-items-core) for create and update, [Line Item Targets](/retail-media/experimental/docs/line-item-targets) for targeting, and [Line Item Creatives](/retail-media/experimental/docs/line-item-creatives) for creative assignment.

## Features

| Page | Description |
| --- | --- |
| [Minimum Bid](/retail-media/experimental/docs/minimum-bid) | Retrieve the minimum bid required for a line item to be eligible to serve. |
