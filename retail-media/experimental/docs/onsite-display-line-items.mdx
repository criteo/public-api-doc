Onsite Display line items sit within a Display campaign and define where and how ads serve — including the retailer, flight dates, and delivery settings.

<Info>
  **Use Line Item Core to create and update Onsite Display line items.** The unified [`POST /line-items`](/retail-media/experimental/docs/line-items-core) endpoint replaces the type-specific creation routes. See [Line Item Core](/retail-media/experimental/docs/line-items-core) for the full create and update reference.
</Info>
