title: Hard Limits
description: All numeric constraints across the Retail Media API in one place.
---

All hard and soft limits across the Retail Media API. Values are enforced at the API level unless noted as a soft limit.

| Constraint | Value | Scope | Notes |
|---|---|---|---|
| Max campaigns per account | 100,000 | Campaigns | |
| Max line items per campaign | 10,000 | Line Items | Non-archived only. Line items are auto-archived 90 days after end date. |
| Max SKUs per line item | 1,500 | Promoted Products | Soft limit |
| Max date range per DSP analytics report | 100 days | Analytics | Data retained for up to 3 years |
| Max date range per billing report | 31 days | Billing | |
| Max rows per analytics response | 10,000,000 | Analytics | Reports truncate at this limit |
| Report file availability | 72 hours | Async downloads | Files expire 72 hours after generation |
| Max product IDs per keyword recommendation request | 1,000 | Keywords | |
| Max product IDs per category recommendation request | 1,000 | Categories | |
| Max bulk IDs per request | 50 | All bulk endpoints | |
| Onsite activity data availability | 6–8 hours | DSP Analytics | Time after activity before it appears in reports |
| Offsite activity data availability | 24 hours | DSP Analytics | |
| Initial attribution data availability | 7–9 hours | DSP Analytics | |
| Final attribution data availability | 74 hours | DSP Analytics | Minor updates possible until 120 hours |
