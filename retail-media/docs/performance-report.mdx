Flexible performance reporting across any level of granularity. Scope the report to an account, campaign, or line item — the output granularity is determined by the dimensions you include.

Supports the full set of performance metrics and dimensions, including video, new-to-brand, and keyword data.

## Prerequisites

- Authenticated with scope `retail-media:read`
- Account, campaign, or line item ID to scope the report

## Steps

This endpoint is asynchronous — see [Async Patterns](/retail-media/docs/async-patterns).

### 1. Submit

[→ `POST /retail-media/reports/performance`](/retail-media/reference/generate-async-performance-report)

Provide exactly one scope filter (`accountIds`, `campaignIds`, or `lineItemIds`), plus `startDate`, `endDate`, `metrics`, and `dimensions`. All five are required.

**Returns:** `reportId` — used in steps 2 and 3.

<Warning>`filters` must contain exactly one scope filter. Passing multiple or none returns `400 Bad Request`.</Warning>

<Note>
  The `winRate` metric is meaningful only for Sponsored Products campaigns. If your account also runs other campaign types, include `campaignType` in `dimensions` (or filter to Sponsored Products) so `winRate` is attributed to the right campaigns.
</Note>

### 2. Poll for status

[→ `GET /retail-media/reports/{reportId}/status`](/retail-media/reference/get-async-export-status)

Poll until `status` is `success` or `failure`.

### 3. Download

[→ `GET /retail-media/reports/{reportId}/output`](/retail-media/reference/get-async-export-output)

Default output format is `json-compact` — a `columns`/`data` array shape rather than an array of row objects.

## Constraints

| Limit | Value |
|---|---|
| Max date range | 100 days — [Hard Limits](/retail-media/docs/hard-limits) |
| Data retention | 3 years |
