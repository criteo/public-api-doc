A balance is the account-level spend cap that funds campaigns. When the combined costs of all linked campaigns exhaust the balance, all associated campaigns stop running — even if they have remaining campaign budgets or scheduled end dates.

  See the full list of endpoints and parameters in the [→ API Reference](/retail-media/reference/get-balances-by-account-id)
</Note>

<Note>
  Learn more about balances in the [CMax Help Center](https://help.retailmedia.criteo.com/kb/guide/en/about-balances-dp2VSA0YeL/Steps/973366).
</Note>

## Balance types

| Type | Funded by | Scope | `retailerId` |
|---|---|---|---|
| **Criteo balance** | Advertiser (Brand or Seller) | Account-wide | `null` |
| **Retailer-budgets balance** | Retailer | Retailer-scoped | Set — must match campaign and line item |

Retailer-budgets balances require the retailer to have authorized the account as a buyer. They are not available for Offsite campaigns.

## Who can do what

| Action | Brand / Seller | Retailer |
|---|---|---|
| View balances | ✓ | ✓ |
| Link campaigns to a balance | ✓ | ✓ |
| Create or edit Criteo balances | — (Billing portal only) | ✓ |
| Create retailer-budgets balances | — (created by Criteo account team) | — (created by Criteo account team) |
| Unlink campaigns from a Criteo balance | ✓ | ✓ |
| Unlink campaigns from a retailer-budgets balance | — | — |

## Balance statuses

| Status | Meaning |
|---|---|
| **Active** | Funds are available and today's date is within the balance start and end dates. Linked campaigns can spend. |
| **Scheduled** | Funds are available but the start date is in the future. Linked campaigns cannot spend yet. |
| **Ended** | Funds are exhausted or the end date has passed. Linked campaigns can no longer spend from this balance. |

## Constraints

- Campaigns must be assigned to at least one balance to run.
- A balance can be linked to multiple campaigns, but it is a **shared spend cap** — it does not allocate or distribute funds between campaigns. Campaign and line item budgets are separate controls.
- A balance can be uncapped. In that case, campaign and line item budgets are the effective spending controls.
- **If a campaign is linked to multiple active balances**, costs are drawn in this order: (1) balance with the soonest end date; (2) if no end dates, balance with the earliest start date; (3) if start dates are also identical, the balance created first.
- Balances must match the campaign on **type** (Criteo vs. Retailer-budgets), **retailer** (for Retailer-budgets), and **demand account**. A mismatch in a bulk request fails the entire batch.
- Retailer-budgets balances cannot be unlinked from a campaign — `DELETE /balances/{balanceId}/campaigns` returns `400 RetailerBilledBalanceImmutable`.
- Use the **supply account ID** when querying balances to discover Retailer-budgets balances. API version `2026-01` or later is required — earlier versions hide them.
