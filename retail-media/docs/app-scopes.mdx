---
title: App Scopes
description: OAuth scopes required per endpoint for the Retail Media API.
---

Retail Media API endpoints are protected by OAuth 2.0 scopes. Each endpoint requires one scope. Calling an endpoint without that scope results in `403 Forbidden` errors at runtime.

<Info>
  Scopes are granted at app creation time and cannot be widened afterwards. If your app is missing a scope, you need to create a new app with the correct scope set and obtain consent again.
</Info>

## Available scopes

| Scope | What it covers |
| ----- | -------------- |
| `RetailMedia_Accounts_Read` | Read access to accounts, brands, sellers, and fees |
| `RetailMedia_Accounts_Manage` | Create and manage accounts, brands, sellers, fees, and consent |
| `RetailMedia_Campaign_Read` | Read access to campaigns, line items, creatives, products, keywords, and catalog data |
| `RetailMedia_Campaign_Manage` | Create and manage campaigns, line items, creatives, products, keywords, and catalog exports |
| `RetailMedia_Analytics_Read` | Read access to performance, revenue, attribution, and reporting endpoints |
| `RetailMedia_Audience_Read` | Read access to audience segments and contact lists |
| `RetailMedia_Audience_Manage` | Create and manage audience segments and contact lists |
| `RetailMedia_Balance_Read` | Read access to balances and balance history |
| `RetailMedia_Balance_Manage` | Create and manage balances, add funds, and change balance dates |
| `RetailMedia_Billing_Read` | Read access to billing and partner reports |
| `RetailMedia_Catalog_Manage` | Create and manage store inventory in the product catalog |

***
