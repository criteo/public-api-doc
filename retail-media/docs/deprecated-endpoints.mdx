This page lists endpoints that have been permanently removed from the Retail Media stable API. Calling a removed endpoint returns `410 Gone`.

<Info>
  Breaking changes are also listed in the [Changelog](/retail-media/changelog). The [Versioning Policy](/retail-media/docs/versioning-policy) explains how `Deprecation` and `Sunset` response headers signal upcoming removals before they take effect.
</Info>

***

## Preferred line item targeting

**Removed: October 14, 2026 — all stable versions**

The individual targeting sub-resources for preferred line items (add-to-basket, audience, and store targeting) have been removed from all stable versions.

| Method | Endpoint |
| ------ | -------- |
| `GET` | `/retail-media/preferred-line-items/{lineItemId}/targeting/add-to-basket` |
| `PUT` | `/retail-media/preferred-line-items/{lineItemId}/targeting/add-to-basket` |
| `POST` | `/retail-media/preferred-line-items/{lineItemId}/targeting/add-to-basket/append` |
| `POST` | `/retail-media/preferred-line-items/{lineItemId}/targeting/add-to-basket/delete` |
| `GET` | `/retail-media/preferred-line-items/{lineItemId}/targeting/audiences` |
| `PUT` | `/retail-media/preferred-line-items/{lineItemId}/targeting/audiences` |
| `POST` | `/retail-media/preferred-line-items/{lineItemId}/targeting/audiences/append` |
| `POST` | `/retail-media/preferred-line-items/{lineItemId}/targeting/audiences/delete` |
| `GET` | `/retail-media/preferred-line-items/{lineItemId}/targeting/stores` |
| `PUT` | `/retail-media/preferred-line-items/{lineItemId}/targeting/stores` |
| `POST` | `/retail-media/preferred-line-items/{lineItemId}/targeting/stores/append` |
| `POST` | `/retail-media/preferred-line-items/{lineItemId}/targeting/stores/delete` |
