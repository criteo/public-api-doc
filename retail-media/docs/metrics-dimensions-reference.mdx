title: Metrics & Dimensions Reference
description: All metrics and dimensions available in Retail Media API reports, with definitions and per-report field lists.
---

Metric and dimension names are case-sensitive. Definitions are listed once below; the [Fields by report](#fields-by-report) section lists which fields apply to each report.

<Info>
  Some reports use legacy names for fields that have canonical names in the Performance report (e.g., `advProductCategory` vs. `productCategory`, `campaignTypeName` vs. `campaignType`). These are noted in the definitions below.
</Info>

## Metrics

| Metric | Description |
|---|---|
| `assistedSales` | Revenue from sales where an ad appeared on the same page within the attribution window but was not the last touch before purchase. |
| `assistedUnits` | Units sold attributed to an assisted ad interaction (ad was seen but not the last touch before purchase). |
| `attributedOrders` | Number of orders attributed to an ad interaction within the attribution window. |
| `attributedSales` | Revenue from sales where the ad was the last touch before purchase within the attribution window. |
| `attributedUnits` | Units sold where the ad was the last touch before purchase within the attribution window. |
| `availablePlacements` | Total placement slots eligible to serve an ad in the reporting period. |
| `capoutHour` | Hour in which the line item's budget cap was reached. |
| `clicks` | Total number of times an ad creative was clicked. |
| `coverageRate` | Ratio of covered placements to total available placements. |
| `coveredPlacements` | Placements with at least one eligible advertiser bid in the auction. |
| `cpc` | Average cost per click (spend ÷ clicks). |
| `cpm` | Average cost per 1,000 impressions (spend ÷ impressions × 1,000). |
| `cpo` | Average cost per attributed order (spend ÷ attributedOrders). |
| `cr` | Conversion rate (attributedOrders ÷ clicks). |
| `ctr` | Click-through rate (clicks ÷ impressions). |
| `daypartingScheduled` | Indicates whether dayparting was active during the capout period (binary: active / inactive). |
| `deliverablePlacements` | Placements technically capable of serving an ad (not blocked or inactive). |
| `fillRate` | Ratio of placements filled with an ad to total available placements. |
| `frequency` | Average number of times the same user was shown an ad in the reporting period. |
| `impressions` | Total ad impressions served; each unique campaign on a page is counted once. |
| `makeGoodSpend` | Spend delivered as compensatory impressions for under-delivery in a prior period. |
| `missedClicks` | Estimated clicks lost because the line item reached its budget cap. |
| `missedImpressions` | Estimated impressions lost because the line item reached its budget cap. |
| `missedSales` | Estimated attributed sales lost because the line item reached its budget cap. |
| `missedSpend` | Estimated spend that would have been incurred had the budget not been capped. |
| `missedTraffic` | Estimated page views lost because the line item reached its budget cap. |
| `netRevenue` | Revenue after deducting rebates and fees. |
| `newToBrandAttributedSales` | Revenue from customers purchasing the brand for the first time. |
| `newToBrandAttributedSalesRate` | Proportion of attributedSales that are new-to-brand purchases. |
| `newToBrandAttributedUnits` | Units sold to first-time purchasers of the brand. |
| `newToBrandAttributedUnitsRate` | Proportion of attributedUnits that are new-to-brand purchases. |
| `nonDeliverableBlockedOptOut` | Placements not served because the user opted out of personalized ads. |
| `nonDeliverableBlockedPageCategory` | Placements not served due to page-category restrictions set by the retailer. |
| `nonDeliverableInactivePlacement` | Placements not served because the placement is currently inactive. |
| `nonDeliverableInsufficientOrganicResults` | Placements not served because organic results were insufficient to meet the required ad-to-organic ratio. |
| `nonDeliverableInvalidTraffic` | Placements excluded due to invalid traffic detection. |
| `nonDeliverablePagesWithUnknownProducts` | Placements on pages where no products could be identified. |
| `nonDeliverablePlacements` | Total placements that could not serve an ad for any reason. |
| `nonDeliverableTestPlacement` | Placements identified as test traffic and excluded from delivery. |
| `nonDeliverableUnmappedCategories` | Placements where the product category could not be mapped to a known category. |
| `numberOfCampaigns` | Count of distinct campaigns active in the reporting period. |
| `numberOfLineItems` | Count of distinct line items active in the reporting period. |
| `numberOfSkus` | Count of distinct SKUs advertised in the reporting period. |
| `openAuctionRevenue` | Revenue generated from open auction (sponsored products) campaigns. |
| `pageViews` | Total page views in the reporting scope. |
| `placementClicks` | Clicks measured at the placement level (all products within the placement). |
| `placementImpressions` | Impressions measured at the placement level. |
| `placementImpressionsCTR` | Click-through rate at the placement level (placementClicks ÷ placementImpressions). |
| `placementImpressionsRevenue` | Revenue attributed to placement-level impressions. |
| `placementsWithCandidates` | Placements where at least one valid ad candidate was returned from the auction. |
| `preferredDealsRevenue` | Revenue generated from preferred deals (onsite display) campaigns. |
| `productClicks` | Clicks recorded on individual products within a placement. |
| `productClicksRevenue` | Revenue attributed to product-level clicks. |
| `productImpressions` | Impressions counted at the individual product level within a placement. |
| `productImpressionsCTR` | Click-through rate at the product level (productClicks ÷ productImpressions). |
| `revenue` | Total gross revenue from ad placements. |
| `roas` | Return on ad spend (attributedSales ÷ spend); may vary based on attribution settings. |
| `sales` | Total attributed sales units in the revenue report. |
| `sampledBidsParticipated` | Sum of bids entered in a 25% random sample of auctions. |
| `sampledBidsWon` | Sum of bids won in a 25% random sample of auctions. |
| `skuPrice` | Average price of the advertised SKU. |
| `spend` | Total media spend by the advertiser; for retailer-billed campaigns, reflects media spend only. |
| `totalSpend` | Total actual spend in the period (used alongside missed metrics in the Missed Opportunities report). |
| `totalUnfilledPlacements` | Total placements not filled with an ad. |
| `transactions` | Total number of attributed transactions. |
| `uncoveredBrokenPlacement` | Uncovered placements due to a broken or misconfigured placement. |
| `uncoveredFilteredOutDemand` | Uncovered placements where all eligible demand was filtered out. |
| `uncoveredNoDemandBrandedKeywordConquestingDisabled` | Uncovered branded keyword placements where keyword conquesting is disabled. |
| `uncoveredNoDemandBrandedKeywordConquestingEnabled` | Uncovered branded keyword placements where conquesting is enabled but no demand exists. |
| `uncoveredNoDemandOptOut` | Uncovered placements because the advertiser opted out of that inventory. |
| `uncoveredNoDemandUnbrandedInventory` | Uncovered unbranded placements with no matching demand. |
| `uncoveredNotPainted` | Uncovered placements that were not rendered on screen. |
| `uncoveredSearchTermWithoutCategory` | Uncovered placements on search pages where no product category was matched. |
| `uncoveredUnusedFormats` | Uncovered placements because no demand exists for the available ad format. |
| `unfilledAdvertiserAuctionSettings` | Unfilled placements due to advertiser auction configuration restrictions. |
| `unfilledCriteoAuctionSettings` | Unfilled placements due to Criteo auction configuration restrictions. |
| `unfilledNotEnoughDemand` | Unfilled placements where eligible demand existed but was insufficient. |
| `unfilledPlacements` | Placements not filled with an ad (the complement of fillRate). |
| `unfilledRetailerAuctionSettings` | Unfilled placements due to retailer auction configuration restrictions. |
| `unfilledReturnedButNotPainted` | Placements where an ad was returned by the ad server but not rendered on screen. |
| `unfilledTotalAuctionConsiderations` | Unfilled placements due to total auction consideration rules. |
| `unfilledTotalAuctionSettings` | Unfilled placements due to overall auction settings. |
| `unfilledUserOptOut` | Unfilled placements because the user opted out of personalized ads. |
| `uniqueVisitors` | Count of distinct users who were shown an ad. |
| `units` | Total product units sold in attributed transactions (revenue report). |
| `videoAvgInteractionRate` | Average rate of user interactions per video impression (mute, pause, expand, etc.). |
| `videoCPC` | Average cost per click on a video ad. |
| `videoCPCV` | Average cost per completed video view (played to 100%). |
| `videoCompletionRate` | Proportion of video ads that were played to completion (100%). |
| `videoImpressions` | Number of video ad impressions served. |
| `videoMuted` | Number of times a viewer muted the video ad. |
| `videoPaused` | Number of times a viewer paused the video ad. |
| `videoPlayingRate` | Proportion of served video ads that began playing. |
| `videoResumed` | Number of times a viewer resumed a paused video ad. |
| `videoStartingRate` | Rate at which video ads started playing after being served. |
| `videoUnmuted` | Number of times a viewer unmuted the video ad. |
| `videoViewability` | Proportion of video ads meeting the MRC viewability standard (≥50% pixels visible for ≥2 continuous seconds). |
| `videoViews` | Number of times a video ad was viewed past the initial frame. |
| `videosPlayedTo100` | Number of video ads played to 100% completion. |
| `videosPlayedTo25` | Number of video ads played to at least 25%. |
| `videosPlayedTo50` | Number of video ads played to at least 50%. |
| `videosPlayedTo75` | Number of video ads played to at least 75%. |
| `videosStarted` | Number of video ads that began playing. |
| `winRate` | Proportion of sampled auction bids won (sampledBidsWon ÷ sampledBidsParticipated; measured on 25% of auctions). |
| `workingMedia` | Spend allocated to media delivery, excluding platform fees. |

| `advertisedEngagement` | Type of engagement (click or impression) that triggered the transaction attribution. |
| `advertisedHour` | Hour the ad was delivered, in the Attributed Transactions report. |
| `advertisedProductCategory` | Category of the product that was advertised at the time of the purchase event. |
| `advertisedProductGtin` | GTIN of the advertised product in an attributed transaction. |

| `attributionSettings` | Attribution model configuration in effect at the time of the event. |
| `attributionWindow` | Look-back window (in days) applied when attributing the transaction. |
| `bidStrategy` | Bidding strategy used by the line item (e.g., target CPC, target ROAS). |
| `brandId` | Unique identifier of the advertised brand. |
| `brandName` | Name of the advertised brand. |

| `creativeId` | Unique identifier of the ad creative. |
| `creativeName` | Name of the ad creative. |
| `creativeTemplateId` | Unique identifier of the creative template used for the ad. |
| `creativeTemplateName` | Name of the creative template used for the ad. |
| `creativeType` | Format category of the ad creative (e.g., banner, video, product carousel). |
| `date` | Date of the reported events (YYYY-MM-DD format). |
| `daysDifference` | Number of days between the ad delivery date and the purchase date. |
| `environment` | Environment in which the ad was served: `app`, `mobile web`, or `web`. |
| `hour` | Hour of the reported events (0–23, in the timezone of the API request). |
| `keyword` | Normalized keyword submitted by the advertiser that matched the search page (stemmed search term). |
| `lineItemEndDate` | Scheduled end date of the line item. |
| `lineItemId` | Unique identifier of the line item. |
| `lineItemName` | Name of the line item. |
| `lineItemStartDate` | Scheduled start date of the line item. |
| `lineItemStatus` | Current operational status of the line item (e.g., `active`, `paused`, `ended`). |
| `mediaType` | Type of ad media served (e.g., `display`, `video`). |
| `pageCategory` | Retailer-defined category of the page where the ad was served. |
| `pageType` | Type of retailer page where the ad was served (`home`, `search`, `product`, etc.). |
| `pageTypeName` | Human-readable page type label. Legacy name — corresponds to `pageType` in the Performance report. |
| `parentAccount` | Identifier of the parent account, for multi-level account hierarchy reporting. |
| `placementId` | Unique identifier of the ad placement slot on the retailer page. |
| `placementName` | Name of the ad placement slot. |
| `productCategory` | Category of the advertised product. Canonical name in the Performance report. |
| `productId` | ID of the advertised product. Canonical name in the Performance report. |
| `productName` | Name of the advertised product. Canonical name in the Performance report. |
| `purchasedDate` | Date the purchase occurred in an attributed transaction. |
| `purchasedHour` | Hour the purchase occurred in an attributed transaction. |
| `purchasedProductCategory` | Product category of the item actually purchased. |
| `purchasedProductGtin` | GTIN of the item actually purchased. |
| `purchasedProductId` | ID of the item actually purchased. |
| `purchasedProductMpn` | Manufacturer part number of the item actually purchased. |
| `purchasedProductName` | Name of the item actually purchased. |
| `retailerCategoryId` | Retailer-specific category ID associated with the product. |
| `retailerCategoryName` | Retailer-specific category name associated with the product. |
| `retailerId` | Unique identifier of the retailer. |
| `retailerName` | Name of the retailer. |
| `saleChannel` | Channel of the sale as recorded in the revenue report (`online`, `in-store`). |
| `saleSellerId` | ID of the seller responsible for the sale in an attributed transaction. |

| `taxonomy1Id` | Retailer taxonomy node ID at hierarchy level 1 (top level). |
