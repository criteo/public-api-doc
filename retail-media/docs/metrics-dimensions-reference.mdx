---
title: Metrics & Dimensions Reference
description: Complete reference of all metrics and dimensions available across Retail Media API reports.
---

This page lists every metric and dimension available in the Retail Media API reporting endpoints. Fields available on both DSP and SSP reports appear in both sections.

<Info>
  Metric and dimension names are case-sensitive. The Performance report uses the current canonical names (e.g., `campaignType`, `productCategory`). Some older report variants (Sync, Revenue) use legacy names for the same fields — these are documented side by side where they differ.
</Info>

## Report types

| Report | Endpoint | Side |
|---|---|---|
| **Performance** | `POST /retail-media/reports/performance` | DSP |
| **Attributed Transactions** | `POST /retail-media/reports/attributed-transactions` | DSP |
| **Missed Opportunities** | `POST /retail-media/reports/missed-opportunities` | DSP |
| **Sync Campaigns / Line Items** | `POST /retail-media/reports/sync/campaigns` · `sync/line-items` | DSP (sync, legacy) |
| **Sync Real-Time** | `POST /retail-media/reports/sync/real-time-performance` | DSP (sync) |
| **Revenue** | `POST /retail-media/reports/revenue` | SSP |
| **Fill Rate** | `POST /retail-media/reports/fillrate` | SSP |
| **Unfilled Placements** | `POST /retail-media/reports/unfilled-placements` | SSP |

## DSP Metrics

| Metric | Description | Available in |
|---|---|---|
| `assistedSales` | Revenue from sales where an ad was viewed within the attribution window but was not the last touch before purchase. | Performance, Sync Campaigns, Sync Line Items |
| `assistedUnits` | Units sold attributed to an assisted ad interaction (ad was seen but not the last touch before purchase). | Performance, Sync Campaigns, Sync Line Items |
| `attributedOrders` | Number of orders attributed to an ad interaction within the attribution window. | Performance, Sync Campaigns, Sync Line Items |
| `attributedSales` | Revenue from sales where the ad was the last touch before purchase within the attribution window. | Performance, Attributed Transactions, Missed Opportunities, Sync Campaigns, Sync Line Items |
| `attributedUnits` | Units sold where the ad was the last touch before purchase within the attribution window. | Performance, Attributed Transactions, Sync Campaigns, Sync Line Items |
| `capoutHour` | Hour in which the line item's budget cap was reached. | Missed Opportunities |
| `clicks` | Total number of times an ad creative was clicked. | Performance, Missed Opportunities, Sync Campaigns, Sync Line Items, Sync Real-Time |
| `cpc` | Average cost per click (spend ÷ clicks). | Performance, Missed Opportunities, Sync Campaigns, Sync Line Items |
| `cpm` | Average cost per 1,000 impressions (spend ÷ impressions × 1,000). | Performance, Missed Opportunities, Sync Campaigns, Sync Line Items |
| `cpo` | Average cost per attributed order (spend ÷ attributedOrders). | Performance, Sync Campaigns, Sync Line Items |
| `ctr` | Click-through rate (clicks ÷ impressions). | Performance, Missed Opportunities, Sync Campaigns, Sync Line Items |
| `daypartingScheduled` | Indicates whether dayparting was active during the capout period (binary: active / inactive). | Missed Opportunities |
| `frequency` | Average number of times the same user was shown an ad in the reporting period (impressions ÷ uniqueVisitors). | Performance, Sync Campaigns, Sync Line Items |
| `impressions` | Total ad impressions served; each unique campaign on a page is counted once. | Performance, Missed Opportunities, Sync Campaigns, Sync Line Items, Sync Real-Time |
| `makeGoodSpend` | Spend delivered as compensatory impressions for under-delivery in a prior period. | Performance |
| `missedClicks` | Estimated clicks lost because the line item reached its budget cap. | Missed Opportunities |
| `missedImpressions` | Estimated impressions lost because the line item reached its budget cap. | Missed Opportunities |
| `missedSales` | Estimated attributed sales lost because the line item reached its budget cap. | Missed Opportunities |
| `missedSpend` | Estimated spend that would have been incurred had the budget not been capped. | Missed Opportunities |
| `missedTraffic` | Estimated page views lost because the line item reached its budget cap. | Missed Opportunities |
| `newToBrandAttributedSales` | Revenue from customers purchasing the brand for the first time. | Performance |
| `newToBrandAttributedSalesRate` | Proportion of attributedSales that are new-to-brand purchases. | Performance |
| `newToBrandAttributedUnits` | Units sold to first-time purchasers of the brand. | Performance |
| `newToBrandAttributedUnitsRate` | Proportion of attributedUnits that are new-to-brand purchases. | Performance |
| `roas` | Return on ad spend (attributedSales ÷ spend); may vary based on attribution settings. | Performance, Missed Opportunities, Sync Campaigns, Sync Line Items |
| `sampledBidsParticipated` | Sum of bids entered in a 25% random sample of auctions. | Performance |
| `sampledBidsWon` | Sum of bids won in a 25% random sample of auctions. | Performance |
| `spend` | Total media spend by the advertiser; for retailer-billed campaigns, reflects media spend only. | Performance, Sync Campaigns, Sync Line Items, Sync Real-Time |
| `totalSpend` | Total actual spend in the period (used alongside missed metrics in the Missed Opportunities report). | Missed Opportunities |
| `uniqueVisitors` | Count of distinct users who were shown an ad. | Performance, Sync Campaigns, Sync Line Items |
| `videoAvgInteractionRate` | Average rate of user interactions per video impression (mute, pause, expand, etc.). | Performance |
| `videoCPC` | Average cost per click on a video ad. | Performance |
| `videoCPCV` | Average cost per completed video view (played to 100%). | Performance |
| `videoCompletionRate` | Proportion of started video ads that played to completion (videosPlayedTo100 ÷ videosStarted × 100). | Performance |
| `videoImpressions` | Number of video ad impressions served. | Performance |
| `videoMuted` | Number of times a viewer muted the video ad. | Performance |
| `videoPaused` | Number of times a viewer paused the video ad. | Performance |
| `videoPlayingRate` | Average percentage of video duration played per started video. Formula: (sum of quartile plays × 0.25) ÷ (4 × videosStarted). | Performance |
| `videoResumed` | Number of times a viewer resumed a paused video ad. | Performance |
| `videoStartingRate` | Rate at which served video ads began playing (videosStarted ÷ placementImpressions). | Performance |
| `videoUnmuted` | Number of times a viewer unmuted the video ad. | Performance |
| `videoViewability` | Proportion of video ads meeting the MRC viewability standard (≥50% pixels visible for ≥2 continuous seconds). Formula: Viewable Impressions ÷ Placement Impressions. Requires OMID support. | Performance |
| `videoViews` | Number of times a video ad was viewed past the initial frame. | Performance |
| `videosPlayedTo100` | Number of video ads played to 100% completion. | Performance |
| `videosPlayedTo25` | Number of video ads played to at least 25%. | Performance |
| `videosPlayedTo50` | Number of video ads played to at least 50%. | Performance |
| `videosPlayedTo75` | Number of video ads played to at least 75%. | Performance |
| `videosStarted` | Number of video ads that began playing. Named `videoStarts` in SSP Revenue reports. | Performance |
| `winRate` | Proportion of sampled auction bids won (sampledBidsWon ÷ sampledBidsParticipated; measured on 25% of auctions). | Performance |
