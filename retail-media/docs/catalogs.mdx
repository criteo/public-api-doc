A catalog is a daily snapshot of all products from the brands and retailers associated with an account. Each account has a single catalog listing all the products it is eligible to promote.

[→ API Reference](/retail-media/reference/create-brand-catalog-export)

## How catalogs work

- Catalogs are updated **once a day**. They reflect the state of the retailer's product feed at the time of the last sync, not real-time inventory.
- Product attributes (price, availability, category) are **scoped to the retailer** — the same product may have different attributes across retailers.
- Brand attributes (brand name, brand ID) are **standardized across retailers**.
- Prices are in the **retailer's currency**.
- GTIN and other universal identifiers are consistent across retailers where available.

## Constraints

- Catalogs are retrieved via asynchronous endpoints — there is no synchronous catalog API.
- Output is a **newline-delimited JSON stream** (`application/x-json-stream`), not a JSON array. Parse it line by line.
- Use `modifiedAfter` to pull only products updated since a given timestamp — recommended for large catalogs to avoid re-downloading the full snapshot daily.
- The `advertisementChannels` filter is an intersection: a product is only returned if it is eligible on **all** listed channels, not any one of them.
