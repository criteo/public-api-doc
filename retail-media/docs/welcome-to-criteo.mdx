## Before you begin

The Criteo Retail Media API uses the same authentication, versioning, and error model as all Criteo APIs. Read these pages before writing your first request:

- [Create your API application](/criteo-apis/docs/create-your-app) — register an app and obtain a client ID
- [Get your credentials](/criteo-apis/docs/get-credentials) — generate the client secret you'll use to authenticate
- [OAuth client credentials setup](/criteo-apis/docs/oauth-app-client-credentials) — exchange your credentials for an access token
- [Rate limits](/criteo-apis/docs/rate-limits) — understand request quotas and how to handle 429 responses
- [API error codes](/criteo-apis/docs/api-error-codes) — reference for all error responses

## Who is this API for?

- **Brands** — You have preferred tools and the development resources to build with our APIs
- **Agencies** — You offer complementary tools to brands who prefer your managed services
- **Partners** — You offer complementary tools to brands or agencies to enrich their retail media campaigns
- **Retailers** — Reach out to your Criteo representative to discuss your needs
- **Marketplaces** — You operate a platform with users who are sellers

## Criteo API Version Tiers Overview

Criteo API versions follow a three-stage lifecycle. Choose the tier that fits your needs — or keep reading to learn what this version offers.
