## Criteo API Version Tiers Overview

Criteo API versions follow a three-stage lifecycle. Choose the tier that fits your needs — or keep reading to learn what this version offers.

<CardGroup cols={3}>
  <Card title="Stable" icon="check-circle">
    **You are here.** Fully supported for 12 months with no breaking changes. The right choice for all production integrations.
  </Card>
  <Card title="Release Candidate" icon="code-branch" href="/retail-media/v2027.01-rc/docs/introduction-to-release-candidate">
    Production-ready preview of the next stable version. Integrate early and you're already on the right version the moment it goes stable.
  </Card>
  <Card title="Experimental" icon="flask" href="/retail-media/experimental/docs/introduction-to-experimental">
    Early access to brand-new features before they're finalized. Contracts may change — not for production use.
  </Card>
</CardGroup>

<Info>
  For the full version lifecycle — deprecation windows, release schedule, fall-forward — see the [Versioning policy](/criteo-apis/docs/versioning-policy).
</Info>
