The Retail Media API lets you create and manage Sponsored Products and Onsite Display campaigns programmatically, pull performance reports, manage audiences and creatives, and build retailer integrations — all through a versioned REST API.

## Before you begin

The Retail Media API uses the same authentication, versioning, and error model as all Criteo APIs. Read these pages before writing your first request:

- [Create your API application](/criteo-apis/docs/create-your-app) — register an app and obtain a client ID
- [Get your credentials](/criteo-apis/docs/get-credentials) — generate the client secret you'll use to authenticate
- [OAuth client credentials setup](/criteo-apis/docs/oauth-app-client-credentials) — exchange your credentials for an access token
- [Rate limits](/criteo-apis/docs/rate-limits) — understand request quotas and how to handle 429 responses
- [API error codes](/criteo-apis/docs/api-error-codes) — reference for all error responses

## Who is this API for?

| Persona | Typical use |
|---|---|
| **Brand** | Build or extend a campaign management tool, automate reporting, or integrate Retail Media into an existing ad platform. |
| **Agency** | Manage campaigns across multiple brand clients programmatically, pull consolidated reporting, and automate budget operations. |
| **Partner / ISV** | Offer complementary tooling to brands or agencies — bid management, analytics, or creative automation. |
| **Retailer** | Set up private market integrations, manage retailer budgets, and configure inventory for demand partners. |
