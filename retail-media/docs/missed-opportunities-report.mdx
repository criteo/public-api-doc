---
title: Missed Opportunities Report
description: Diagnose budget cap-out and estimate missed delivery for DSP campaigns.
---

This report identifies when line items exhaust their daily budget before the day ends, causing them to stop participating in eligible auctions. Use it to quantify delivery shortfalls and decide whether to increase budgets or adjust pacing.

<Info>
  This is a diagnostic report — it covers delivery shortfalls only. For impressions, clicks, and revenue, use the [Performance Report](/retail-media/docs/performance-report).
</Info>

## Before you start

| Requirement | Detail |
|---|---|
| Scope | `retail-media:read` |
| Account, campaign, or line item ID | Used to scope the report — exactly one required |

## Steps

This endpoint is asynchronous — [Async Patterns](/retail-media/docs/async-patterns).

### 1. Submit

[→ `POST /retail-media/reports/missed-opportunities`](/retail-media/reference/generate-async-missed-opportunities-report)

Provide exactly one scope filter (`accountIds`, `campaignIds`, or `lineItemIds`), plus `startDate`, `endDate`, `dimensions`, and `metrics`. All five are required.

**Returns:** `reportId` — used in steps 2 and 3.

<Warning>`filters` must contain exactly one scope filter. Passing multiple or none returns `400 Bad Request`.</Warning>

### 2. Poll for status

[→ `GET /retail-media/reports/{reportId}/status`](/retail-media/reference/get-async-export-status)

Poll every 5–10 seconds until `success` or `failure`.

### 3. Download

[→ `GET /retail-media/reports/{reportId}/output`](/retail-media/reference/get-async-export-output)

Returns one row per day per combination of requested dimensions. Default format: `json-compact`.

<Warning>Calling this before status is `success` returns an error.</Warning>

## Constraints

| Limit | Value |
|---|---|
| Max date range | 100 days — [Hard Limits](/retail-media/docs/hard-limits) |
| Data retention | 3 years |
| File availability | 72 hours after generation |

## Metrics & Dimensions

See [Metrics & Dimensions Reference](/retail-media/docs/metrics-dimensions-reference) for the full list of available fields for this report.

## Common errors

| Error | Cause | Fix |
|---|---|---|
| `400` | Multiple or missing scope filter | Use exactly one of `accountIds`, `campaignIds`, or `lineItemIds` |
| `400` | Date range exceeds 100 days | Reduce the range to 100 days or fewer |
| `400` | `startDate` older than 3 years | Use a more recent start date |
| `404` | Invalid `reportId` | Check the ID returned from step 1 |
| `410` | Report expired | Files expire after 72 hours — resubmit |

## Migrating from `reportType: capout`

Replace your existing call on `/reports/campaigns` or `/reports/line-items` with a call to this endpoint. The underlying data is unchanged.

**Endpoint change:**

```
POST /reports/campaigns   →   POST /reports/missed-opportunities
POST /reports/line-items  →   POST /reports/missed-opportunities
```

**Request shape changes:**

- Replace the top-level `accountId` / `campaignId` / `lineItemId` fields with a `filters` object containing `accountIds[]`, `campaignIds[]`, or `lineItemIds[]` arrays
- Add required `dimensions[]` and `metrics[]` arrays to select output columns
- `startDate` and `endDate` are now required (`YYYY-MM-DD` only — timestamps are rejected)
- Remove `reportType: capout` — it is not accepted on this endpoint

**Metric renames:**

| Old name | New name |
|----------|----------|
| `capoutMissedClicks` | `missedClicks` |
| `capoutMissedImpressions` | `missedImpressions` |
| `capoutMissedSales` | `missedSales` |
| `capoutMissedSpend` | `missedSpend` |
| `capoutMissedTraffic` | `missedTraffic` |
| `capoutHour` | `capoutHour` *(unchanged)* |

**Dimension changes:**

`daypartingScheduled` has moved from a dimension to a metric — add it to `metrics[]` instead of `dimensions[]`.
