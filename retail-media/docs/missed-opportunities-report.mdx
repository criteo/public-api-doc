---
title: Missed Opportunities Report
description: Diagnose budget cap-out and estimate missed delivery for DSP campaigns.
---

This report identifies when line items exhaust their daily budget before the day ends, causing them to stop participating in eligible auctions. Use it to quantify delivery shortfalls and decide whether to increase budgets or adjust pacing.

<Info>
  This is a diagnostic report — it covers delivery shortfalls only. For impressions, clicks, and revenue, use the [Performance Report](/retail-media/docs/performance-report).
</Info>

## Before you start

| Requirement | Detail |
|---|---|
| Scope | `retail-media:read` |
| Account, campaign, or line item ID | Used to scope the report — exactly one required |

## Submit

This endpoint is asynchronous — see [Async Patterns](/retail-media/docs/async-patterns).

[→ `POST /retail-media/reports/missed-opportunities`](/retail-media/reference/generate-async-missed-opportunities-report)

Provide exactly one scope filter (`accountIds`, `campaignIds`, or `lineItemIds`), plus `startDate`, `endDate`, `dimensions`, and `metrics`. All five are required.

<Warning>`filters` must contain exactly one scope filter. Passing multiple or none returns `400 Bad Request`.</Warning>

## Constraints

| Limit | Value |
|---|---|
| Max date range | 100 days — [Hard Limits](/retail-media/docs/hard-limits) |
| Data retention | 3 years |
| File availability | 72 hours after generation |

## Metrics & Dimensions

See [Metrics & Dimensions Reference](/retail-media/docs/metrics-dimensions-reference) for the full list of available fields for this report.

## Common errors

| Error | Cause | Fix |
|---|---|---|
| `400` | Multiple or missing scope filter | Use exactly one of `accountIds`, `campaignIds`, or `lineItemIds` |
| `400` | Date range exceeds 100 days | Reduce the range to 100 days or fewer |
| `400` | `startDate` older than 3 years | Use a more recent start date |
| `404` | Invalid `reportId` | Check the ID returned from step 1 |
| `410` | Report expired | Files expire after 72 hours — resubmit |
