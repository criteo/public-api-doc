---
title: Conceptual Map
description: How the core objects in the Retail Media API relate to each other.
---

```mermaid
graph TD
    Account -->|"owns 1..N"| Campaign
    Account -->|"owns 1..N"| Balance
    Account -->|"has"| Catalog
    Account -->|"owns"| Audience
    Account -->|"owns"| Creative
    Balance -->|"funds N..N"| Campaign
    Campaign -->|"contains 1..N"| LineItem["Line Item"]
    LineItem -->|"targets 1"| Retailer
    LineItem -->|"contains 1..N"| PromotedProduct["Promoted Product"]
    LineItem -->|"applies"| Audience
    LineItem -->|"applies"| Targeting["Targeting (Store / ATB)"]
    LineItem -->|"uses"| Creative
    Catalog -->|"source for"| PromotedProduct
```

| Object | Role |
|---|---|
| Account | Top-level entity. All campaigns, balances, catalogs, audiences, and creatives belong to an account. |
| Campaign | Groups line items under a shared marketing objective and attribution window. |
| Balance | Budget object that funds one or more campaigns. A campaign can draw from multiple balances. |
| Line Item | Executes the campaign at a specific retailer. Controls bid, budget, targeting, and promoted products. |
| Promoted Product | A product from the catalog assigned to a line item for promotion. |
| Catalog | The account's product inventory. Multiple catalog types available (brand, seller). Source for selecting promoted products. |
| Retailer | The retail platform where ads are served. Each line item targets exactly one retailer. |
| Audience | A named set of users defined by one or more segments. Created at account level, applied to Onsite Display line items as targeting. |
| Creative | A display ad built from a retailer template. Created at account level, applied to Onsite Display line items. |
| Targeting | Store lists or add-to-basket rules applied to a line item alongside or instead of audiences. Requires initialization before use. |
