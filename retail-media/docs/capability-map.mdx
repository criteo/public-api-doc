## Overview

The Retail Media API exposes capabilities across ten domains. Use this page to find the right endpoint for what you want to build, or to understand the full scope of what the API supports.

All endpoints below are available in the stable `2026-07` version of the API. Replace `/2026-07/` with the version prefix for your target version.

- [Account management](#account-management) — access and configure accounts, brands, and sellers
- [Campaigns](#campaigns) — create and manage campaigns and their budgets
- [Line items](#line-items) — set up ad placements for Sponsored Products and Onsite Display
- [Keywords](#keywords) — manage keyword targeting and bids for Sponsored Products
- [Promoted products](#promoted-products) — control which products are advertised on a line item
- [Creatives and assets](#creatives-and-assets) — build display ads from retailer templates
- [Catalog and retailer planning](#catalog-and-retailer-planning) — explore retailers, browse categories, and export product data
- [Balances and billing](#balances-and-billing) — fund campaigns and pull billing reports
- [Audiences](#audiences) — build and manage audience segments for targeting
- [Performance reporting](#performance-reporting) — measure campaign results with async and sync reports

<Note>
  These sections match the grouping in the [API Reference](/retail-media/v2026.07/reference).
</Note>

## Account management

Discover and configure the accounts, brands, and sellers that campaigns run under. Start here to find account IDs, set up brand and seller relationships, manage platform fees, and verify the identity of the calling API credentials.

| Capability | Method | Endpoint |
| ---------- | ------ | -------- |
| List accessible accounts | `GET` | `/retail-media/accounts` |
| Search brands | `POST` | `/retail-media/brands/search` |
| Search sellers | `POST` | `/retail-media/accounts/sellers/search` |
| List brands on an account | `GET` | `/retail-media/accounts/{accountId}/brands` |
| Add brands to an account | `POST` | `/retail-media/account-management/accounts/{accountId}/brands/add` |
| Remove brands from an account | `POST` | `/retail-media/account-management/accounts/{accountId}/brands/remove` |
| Create a brand account | `POST` | `/retail-media/account-management/accounts/{accountId}/create-brand-account` |
| Create a seller account | `POST` | `/retail-media/account-management/accounts/{accountId}/create-seller-account` |
| List private market child accounts | `GET` | `/retail-media/account-management/accounts/{accountId}/private-market-child-accounts` |
| Update seller settings | `PUT` | `/retail-media/account-management/accounts/{accountId}/sellers` |
| Grant consent | `POST` | `/retail-media/accounts/{accountId}/grant-consent` |
| Search account fees | `POST` | `/retail-media/accounts/fees/search` |
| Update account fees | `POST` | `/retail-media/accounts/fees/update` |
| Check API identity | `GET` | `/retail-media/me` |

## Campaigns

Create and manage campaigns — the containers that group line items and hold shared attribution settings, flight dates, and budget. A campaign must exist and be linked to at least one balance before any line item can deliver.

| Capability | Method | Endpoint |
| ---------- | ------ | -------- |
| List campaigns for an account | `GET` | `/retail-media/accounts/{account-id}/campaigns` |
| Create a campaign | `POST` | `/retail-media/accounts/{account-id}/campaigns` |
| Get a campaign | `GET` | `/retail-media/campaigns/{campaignId}` |
| Update a campaign | `PUT` | `/retail-media/campaigns/{campaignId}` |
| Get campaign budget overrides | `GET` | `/retail-media/campaigns/{campaignId}/campaign-budget-overrides` |
| Update campaign budget overrides | `PUT` | `/retail-media/campaigns/{campaignId}/campaign-budget-overrides` |
| Link campaigns to a balance | `POST` | `/retail-media/balances/{balanceId}/campaigns/append` |
| Unlink campaigns from a balance | `POST` | `/retail-media/balances/{balanceId}/campaigns/delete` |

## Line items

Configure the individual ad placements within a campaign. Sponsored Products line items compete in auction and target by keyword or category; Onsite Display line items run on preferred deals and target by audience, add-to-basket behavior, or store. Both types share endpoints for budget overrides and bid multipliers.

### Sponsored Products (auction)

| Capability | Method | Endpoint |
| ---------- | ------ | -------- |
| List auction line items for a campaign | `GET` | `/retail-media/campaigns/{campaignId}/auction-line-items` |
| Create an auction line item | `POST` | `/retail-media/campaigns/{campaignId}/auction-line-items` |
| Get an auction line item | `GET` | `/retail-media/auction-line-items/{lineItemId}` |
| Update an auction line item | `PUT` | `/retail-media/auction-line-items/{lineItemId}` |
| Get bid multipliers | `GET` | `/retail-media/line-items/{line-item-id}/bid-multipliers` |
| Update bid multipliers | `PUT` | `/retail-media/line-items/{line-item-id}/bid-multipliers` |
| Get line item budget overrides | `GET` | `/retail-media/line-items/{lineItemId}/line-item-budget-overrides` |
| Update line item budget overrides | `PUT` | `/retail-media/line-items/{lineItemId}/line-item-budget-overrides` |

## Keywords

Add and manage keyword targets for Sponsored Products line items. Set individual bids per keyword, add or remove keywords in bulk, and submit them for retailer review before they can serve.

| Capability | Method | Endpoint |
| ---------- | ------ | -------- |
| List keywords on a line item | `GET` | `/retail-media/line-items/{id}/keywords` |
| Add or remove keywords | `POST` | `/retail-media/line-items/{id}/keywords/add-remove` |
| Set keyword bids | `POST` | `/retail-media/line-items/{id}/keywords/set-bid` |
| Submit keywords for review | `POST` | `/retail-media/line-items/{line-item-id}/keywords/review` |
| Get keywords in-review report | `GET` | `/retail-media/accounts/{account-id}/keywords/in-review-report` |

## Promoted products

Specify which products appear on a line item and control their active state. Each product can carry its own bid; a line item supports up to 500 promoted products.

| Capability | Method | Endpoint |
| ---------- | ------ | -------- |
| List promoted products on a line item | `GET` | `/retail-media/line-items/{line-item-id}/products` |
| Add products to a line item | `POST` | `/retail-media/line-items/{line-item-id}/products/append` |
| Remove products from a line item | `POST` | `/retail-media/line-items/{line-item-id}/products/delete` |
| Pause products on a line item | `POST` | `/retail-media/line-items/{line-item-id}/products/pause` |
| Unpause products on a line item | `POST` | `/retail-media/line-items/{line-item-id}/products/unpause` |

## Performance reporting

Measure what your campaigns delivered. Async reports cover the full range of metrics and dimensions; submit a report, poll for completion, then download the output. Sync reports return results immediately for lightweight real-time checks.

### Asynchronous reports

| Capability | Method | Endpoint |
| ---------- | ------ | -------- |
| Start a performance report | `POST` | `/retail-media/reports/performance` |
| Start an attributed transactions report | `POST` | `/retail-media/reports/attributed-transactions` |
| Start a fill rate report | `POST` | `/retail-media/reports/fillrate` |
| Start a missed opportunities report | `POST` | `/retail-media/reports/missed-opportunities` |
| Start a revenue report | `POST` | `/retail-media/reports/revenue` |
| Start an unfilled placements report | `POST` | `/retail-media/reports/unfilled-placements` |
| Get report status | `GET` | `/retail-media/reports/{reportId}/status` |
| Download report output | `GET` | `/retail-media/reports/{reportId}/output` |

### Synchronous reports

| Capability | Method | Endpoint |
| ---------- | ------ | -------- |
| Sync campaign report | `POST` | `/retail-media/reports/sync/campaigns` |
| Sync line item report | `POST` | `/retail-media/reports/sync/line-items` |
| Sync attributed transactions report | `POST` | `/retail-media/reports/sync/attributed-transactions` |
| Sync real-time performance report | `POST` | `/retail-media/reports/sync/real-time-performance` |
